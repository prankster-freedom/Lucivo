# 回遊する文書

この回廊には「次へ」がない。歩いた分だけ、文書が進む。立ち止まれば、壁の言葉がこちらを向く。

## 背景

### めくる発表は、現在地を見失う

スライドは 1 枚ずつ切り替わる。聴き手に見えるのは、いつも「今の 1 枚」だけで、全体のどこにいるのかは、話し手の言葉に頼るしかない。

- 止まった画面が、1 枚の誌面になる
- 移動は、決まった動きを眺めるだけ
- 前後の文脈が、画面から消える

```mermaid
flowchart LR
  S1["今の 1 枚"] --> S2["次の 1 枚"] --> S3["その次の 1 枚"]
```

> 「どこを話しているのか」は、位置で伝わる。

## 課題

### 止まっても、空間であること

ページをめくるのではなく、空間を移動する。前後の見出しや図が同じ廊下の奥と手前に見え続けることで、自分の立ち位置が自然と分かる。

- 止まれば、壁の言葉がこちらを向く
- 歩けば、奥の空間がひらけていく
- 重要な見出しは、門として通り抜ける

## 解決策

### 歩くことが、読むことになる

Markdown の見出し・本文・図を、そのまま廊下と広間と小部屋に置き換える。読み手は自分の足取りで、文書の全体像をたどっていく。

- 章の見出し（`h2`）が、空間を区切る門になる
- 図表（Mermaid）の前では、天井の高い広間がひらく
- 引用や注記は、静かな小部屋の銘板として佇む

```mermaid
flowchart LR
  C1["01 背景"] --> C2["02 課題"] --> C3["03 解決策"]
```
