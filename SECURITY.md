# Security Policy / セキュリティポリシー

[English](#english) | [日本語](#日本語)

---

## English

### Reporting a Vulnerability

If you discover a security vulnerability, please do not report it in a public Issue or Pull Request. Instead, use GitHub's private vulnerability reporting:

1. Open the repository's [Security tab](https://github.com/prankster-freedom/Lucivo/security).
2. Select **Report a vulnerability**.
3. Provide the affected version, steps to reproduce, and expected impact.

Because this project is maintained by an individual developer, response times cannot be guaranteed.

### Supported Versions

Security fixes are provided for the latest release only.

## 日本語

### 脆弱性の報告

脆弱性を見つけた場合は、公開の Issue や Pull Request に書かず、GitHub の非公開の脆弱性報告を使ってください。

1. リポジトリの [Security タブ](https://github.com/prankster-freedom/Lucivo/security) を開く
2. **Report a vulnerability** を選ぶ
3. 影響を受ける版、再現の手順、想定される影響を記入する

個人で開発しているため、回答までの期間は約束できません。

### 対象の版

修正は、最新のリリースに対して行います。
