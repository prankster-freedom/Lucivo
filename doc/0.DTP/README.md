# DTP 全体設計書

Lucivo の Visualモード（Visual Stage）の誌面設計の全体方針を定める。feature 別の確定デザイン仕様は `features/`、ラフ案は `roughs/`、素材は `assets/` で管理する（dtp スキル）。

- 対象: Visualモードの文書表示（ヒーロー、スラブ、スラブ内の本文と図版の割り付け、ベクター装飾素材、および講演・展示でのインタラクティブ・スポットライト演出）。図の中の装飾（ノード・エッジ）は `FR-003` の 4 スタイルの定義に従い、本書では扱わない。
- 上位の方針: [プロダクトコンセプト](../1.SRS.md#11-プロダクトコンセプト)（Visualモードは見た目の品質を優先し、閲覧操作のリアルタイム性を保つ）、[ブランドコンセプト](../1.SRS.md#12-ブランドコンセプトlucivo--brand-concept-sheet)、[製品名称コンセプト仕様書](product-name-concept.md)

## DTP-001 トーン＆マナー

- **世界観**: 展示パネル・カンファレンスのステージのように、1 章（`h2`）を 1 枚のパネル（スラブ）として見せる。章の内容に合った誌面の型（雛形）で割り付け、どの章も同じ箱に流し込んだ印象を与えない。
- **主従**: 1 枚のスラブの主役は 1 つに絞る（言いたいことの一文、要点の並び、手順、図）。主役は大きさ・色・余白で示し、過剰な装飾では示さない。
- **装飾の質感とベクター素材**: 角丸（スラブ 22px、カード 16px）、柔らかい影（不透明度 0.06〜0.12）、細い線（1〜2px）に加え、要所に専用設計のベクター装飾素材（`AST-005` ヒーロー・プリズムエンブレム、`AST-006` ステートメント引用モニュメント、`AST-007` 要点カード・コーナーファセット、`AST-008` 手順フロー・方向シェブロン）を配し、簡易ビューアーの CSS 装飾では出せない細部の質感を仕立てる（`RGH-006`）。
- **静的な紙面に限定しないライブステージ性**: イベントや講演の現場で聴衆の視線を誘導できるよう、ホバー時の繊細な質感応答、クリックによる **インタラクティブ・スポットライト**（要点カードの注目、手順ステップの進行ハイライト、STAGE バッジによるスラブ注目）、製品名「Lucivo（Luc＝光・透明 ＋ Vivo＝鮮明・躍動）」を象徴する **シグナル・ライト（図の構造に沿って上流から下流へ伝わり、届いたノードが反応する光）**、および章を 1 シーンとして全画面で見せる **ステージ発表**、発表中に全シーンを実物のまま並べる **俯瞰（ライトテーブル）**、マウスの位置に光を当てる **光のポインター** を備える（`DTP-SHOW-070`, `080`, `DTP-VTPL-090`, `DTP-LIGHT-010`〜, `DTP-SHOW-010`〜, `RGH-007`, `008`, `RGH-010`〜`012`）。方向性を持たない無秩序な背景パーティクルは読解を損なうため行わない（`RGH-903`）。
- **表紙と表も誌面として仕立てる**: 文書の最初の 1 枚は、フロントマターと章の構成から組む表紙（`DTP-VTPL-100`）とし、展示パネルの扉として何の文書かと章の地図を示す。表は格子で囲まず、横の罫線と見出しの下のアクセントの線で組み、数値の列は右揃え・等幅の数字で桁をそろえる（`DTP-VTPL-110`）。簡易ビューアーの表示が最も残りやすい扉と表に、誌面の文法を通す（`RGH-013`, `RGH-101`）。
- **記法を増やさない**: 雛形とインタラクションはすべて標準の Markdown の記述パターンから自動で有効にする。独自の記法は設けない（`FR-015` と同じ方針。`RGH-901`）。

## DTP-003 配色

雛形のアクセント色とベクター素材（`AST-005`〜`008`）の塗りは、インフォグラフィックスタイル（`FR-003`）ごとに 4 色（`--vs-c1`〜`--vs-c4`）を持ち、図の配色と同じ調子で誌面をまとめる。ブランドカラー（ダークスレート基調）は Visualモードの配色には使わない（[ブランドコンセプト](../1.SRS.md#12-ブランドコンセプトlucivo--brand-concept-sheet)）。ただし、発表の操作のための光（光のポインター、俯瞰の選択の輪。`DTP-SHOW-070`, `080`）は文書の中身ではなく Lucivo 自身の表現のため、ブランドのアクセントライト（ペールシアン・ルミナスホワイト）を使う。

| スタイル    | `--vs-c1` | `--vs-c2` | `--vs-c3` | `--vs-c4` | 調子の出どころ                               |
| :---------- | :-------- | :-------- | :-------- | :-------- | :------------------------------------------- |
| `shapes`    | `#E29578` | `#EBB453` | `#6CC4C9` | `#9CCB86` | Pastel Shapes のノードのグラデーション（コーラル、アンバー、アクア、ライム） |
| `cards`     | `#E29578` | `#E6B34B` | `#A3B4E4` | `#6DB1B4` | 2-Tier Cards の 4 色バー                     |
| `circles`   | `#D45D53` | `#7EA6BF` | `#ECB674` | `#7D9763` | Vibrant Circles の 5 色サークル（先頭 4 色） |
| `editorial` | `#D68C8C` | `#8FA876` | `#C9A66B` | `#8FA3B8` | Editorial Cream のダスティローズとセージ     |

- 文字に色を使うとき（カードの番号など）は、アクセント色 70% に、Light では濃紺（`#0F172A`）、Dark では白を 30% 混ぜた色（`color-mix`）にして、背景とのコントラスト比 3:1 以上（大きな太字の基準）を確保する。
- アクセント色を背景にした上の文字（手順の番号）は濃紺（`#1E293B`）とする。大きな太字（1rem 以上・800）のため、コントラスト比 3:1 以上を目安にする。
- 章番号のバッジ（`STAGE nn`）、ヒーローのプリズムエンブレム（`AST-005`）および 4 色バーも、この 4 色を使う。

## DTP-005 ブランドロゴとアプリケーション外枠の配置

[製品名称コンセプト仕様書](product-name-concept.md) の「丸みのある等幅フォント（ソフトなラウンド・ターミナル）」と「ルミナスシアン／ディープスレート」のブランド方針に基づき、アプリケーションのブランド表示には Light / Dark それぞれに最適化した公式ベクターロゴ素材（`AST-010`〜`012`）を配置し、`body[data-appearance]` の切り替えに連動させる。

| 箇所                    | 使用素材                                                  | 表示寸法・配置ルール |
| :---------------------- | :-------------------------------------------------------- | :------------------- |
| ブラウザタブ（Favicon） | `AST-010`（`assets/logos/{light,dark}/favicon.svg`）      | `32×32` viewBox。外観（Light / Dark）の切り替えに連動して `<link id="app-favicon">` の参照先を更新する |
| メインヘッダー左端      | `AST-011`（`assets/logos/{light,dark}/logo_capsule.svg`） | 高さ `2rem`（`32px`、ヘッダー内ボタン群と同じ高さ）で配置し、ファイルメニューボタンの左に並べる |
| 初期案内画面（`.empty-guide`）上部 | `AST-012`（`assets/logos/{light,dark}/logo_full.svg`） | 高さ `4.5rem`（`72px`、最大幅 `100%`）・中央揃えで掲出し、その下に案内見出しとモード紹介カードを配置する |

ヘッダーと初期案内画面のロゴは、公開リポジトリへのリンクにする（`FR-024`）。ロゴの見た目は変えず、マウスを載せたときに少し薄くし（不透明度 `0.82`）、キーボードで選んだときはアクセント色の輪郭線を出す。初期案内画面の最後には、「最新版はこちら」とリンク（等幅、アクセント色、下線）を、モードの切替の説明と同じ控えめな文字で 1 行置く。その次の行に、現在の版（等幅）と「更新を確認」ボタン（丸い小さなボタン。マウスを載せるとアクセント色）、確認の結果を、同じ控えめな文字で中央にそろえて置く（`FR-049`）。

## DTP-006 操作部の状態の示し方

アプリケーションの外枠の操作部は、「押すと何が起きるか」ではなく「今どの状態か」を示す。

- **二者択一の状態は、2 つ並びの切り替え（`.pill-container` + `.pill-btn`）で示す**: Split / Canvas / Code、高速モード / Visualモード、エディタの `閲覧` / `編集`（`FR-014`）を同じ形に揃える。今の状態のほうを選択中（`is-active`: 面の背景と影、濃い文字）にし、もう一方は淡い文字のままにする。
  - アクセント色の枠と淡い背景のボタンを、状態の表示と並べて置かない。選択中の印と見分けにくく、押す前から押した後の状態に見えるため（`閲覧` / `編集` の切り替えの以前の形「読み取り専用」＋アクセント色の「編集」ボタンで、編集中に見えた）。
  - エディタのヘッダーの切り替えは、ヘッダーの高さ（`2rem`）に収めるため、文字を `10px`、左右の余白を `9px` に詰める。
- **効かない操作は出さない**: デザインスタイルのバー（パステル図形 / 2段カード / 5色サークル / クリームチャート）は Visualモードの配色・装飾にしか効かないため、Visualモードのときだけ表示する（`FR-003`）。高速モードでは、その分（`36px`）だけエディタとプレビューを広げる。

## DTP-007 直接操作の手がかり（図のドラッグ、ファイルのドロップ）

操作部を増やさずに使える直接操作は、操作できる場面でだけ手がかりを出し、普段の画面を変えない。

- **図のドラッグ（`FR-038`）**: スクロール表示の図の上でだけ、カーソルを `grab`（ドラッグ中は `grabbing`）にする。収まっている図ではカーソルを変えず、動かせないものを動かせるように見せない。Ctrl + ホイールの拡大・縮小（`FR-039`）は、倍率のバッジなどをカードに足さず、図の大きさそのもので示す。Visualモードのカードのヘッダーを増やさないため。
- **ファイルのドロップ（`FR-041`）**: ファイルをドラッグしている間だけ、画面全体に受け付けの表示を重ねる。
  - 画面全体: スレートの半透明（`rgba(15, 23, 42, 0.55)`）とぼかし（`6px`）で、下の文書を沈める。
  - 中央のパネル: 濃いスレート（`rgba(15, 23, 42, 0.72)`）の角丸（`1.5rem`）に、ペールシアン（`#A5F3FC` 系）の破線の枠（`2px`）と淡い光を付ける。下向きの矢印のアイコン、「ドロップして開く」（`1.125rem`・700）、開ける拡張子（等幅・`0.75rem`）を縦に並べる。
  - 文書の中身ではなく Lucivo 自身の表現のため、発表の操作の光（`DTP-SHOW-070`）と同じく、ブランドのアクセントライトを使う（`DTP-003`）。外観（Light / Dark）とスタイルによらず、同じ見た目にする。
  - 出入りは `0.15s` のフェードと、パネルのわずかな拡大（`0.97` → `1`）にとどめる。動きを減らす設定（`prefers-reduced-motion`）では動かさない。印刷には出さない。

## DTP-008 フォルダの一覧と、開く・保存のメニュー

フォルダの一覧（`FR-044`）は、文書を主役にしたまま、同じフォルダの資料を行き来するための脇役として、エディタの左に細く置く。

- **一覧（`#folder-pane`）**: 幅 `15.5rem`。背景は `--panel-bg`、右に 1px の `--border-subtle` の線を引き、エディタの列と同じ面に並べる。
  - 見出しはエディタの見出しと同じ高さ（`2rem`）と面（`--panel-sub`）にそろえ、アクセント色のフォルダのアイコン、フォルダの名前（`11px`・700。長い名前は `…` で切る）、「フォルダを閉じる」（×）、「一覧を隠す」（«）を並べる。ボタンは `--text-muted` の線のアイコンだけにし、押せる範囲（`1.5rem` 角）に触れたときだけ面を出す。
  - サブフォルダの区切りは、等幅（JetBrains Mono）`10px`・700 の `--text-muted` で `docs/sub/` のようにパスを示す。ファイルは、ファイルのアイコンと名前（`12px`、`--text-secondary`）で並べる。
  - 開いているファイルは、操作部の選択中の示し方（`DTP-006`）に合わせ、淡いアクセントの面（`--accent-soft`）、濃い文字（`--text-primary`・700）、左端の 3px のアクセントの線で示す。アイコンもアクセント色にする。
- **隠したとき（`#btn-folder-show`）**: 幅 `1.75rem` の帯だけを残し、フォルダのアイコンと開く向きの矢印（»）を縦に並べる。面は `--panel-sub`。触れたときはアイコンをアクセント色にする。
- **狭い画面（幅 1024px 未満）**: 一覧はエディタとプレビューの上に重ね、右側に影を付けて浮かせる。隠したときは、帯の代わりに、左下に影を付けた丸いボタン（`2.75rem`）を浮かせる。エディタの見出しに重ねないため。
- **出さない場面**: ステージ発表と印刷。
- **開く・保存のメニュー（`FR-043`）**: 「開く」「保存」のボタンは、どちらも同じ形（`2rem` の高さ、`--panel-sub` の面、線のアイコン＋文字）にして対に見せる。メニューの見た目は従来のファイルメニュー（`.file-menu`）と同じにする。保存メニューの「Markdown を保存」には、保存するファイル名を括弧で添え、何が保存されるかを押す前に示す。

## DTP-009 フォルダ構成のツリー

フォルダ構成（`FR-047`）は、コードブロックと同じ面に置き、罫線の文字の代わりに、細い線で階層を示す。

- **面**: 背景 `--panel-sub`、1px の `--border-strong` の枠、角丸 `10px`。コードブロック（`DD-MD-015`）と同じ面にして、本文と区別する。Visualモードでは、カードの面に寄せた背景と淡い影にして、誌面のカードと調子をそろえる。
- **線**: 1 段 `1.35rem`、線は `1.5px`、色は `--text-muted` を 55% にした淡い色。最後の子の角は小さく丸める。行の高さ（`1.75rem`）を詰め、縦線を途切れさせない。
- **アイコン**: フォルダだけを塗りのアイコンにし、アクセント色（Visualモードは、スタイルの 1 色目を 80% にした色）にする。ファイルは線のアイコンで `--text-muted` にし、文書・画像・コード・そのほかを形で見分ける。色を増やさず、構造（フォルダ）だけが目に入るようにする。
- **文字**: 名前は等幅（JetBrains Mono）`0.78rem`、根は太字。注釈は本文の書体で `--text-secondary`、名前の列から `2.5rem` 離した列にそろえる。省略の行（`...`）はアイコンを出さず淡くする。
