# DTP 全体設計書

Lucivo の Visualモード（Visual Stage）の誌面設計の全体方針を定める。feature 別の確定デザイン仕様は `features/`、ラフ案は `roughs/`、素材は `assets/` で管理する（dtp スキル）。

- 対象: Visualモードの文書表示（ヒーロー、スラブ、スラブ内の本文と図版の割り付け、ベクター装飾素材、および講演・展示でのインタラクティブ・スポットライト演出）。図の中の装飾（ノード・エッジ）は `FR-003` の 4 スタイルの定義に従い、本書では扱わない。
- 上位の方針: [プロダクトコンセプト](../1.SRS.md#11-プロダクトコンセプト)（Visualモードは見た目の品質を優先し、閲覧操作のリアルタイム性を保つ）、[ブランドコンセプト](../1.SRS.md#12-ブランドコンセプトlucivo--brand-concept-sheet)、[製品名称コンセプト仕様書](product-name-concept.md)

## DTP-001 トーン＆マナー

- **世界観**: 展示パネル・カンファレンスのステージのように、1 章（`h2`）を 1 枚のパネル（スラブ）として見せる。章の内容に合った誌面の型（雛形）で割り付け、どの章も同じ箱に流し込んだ印象を与えない。
- **主従**: 1 枚のスラブの主役は 1 つに絞る（言いたいことの一文、要点の並び、手順、図）。主役は大きさ・色・余白で示し、過剰な装飾では示さない。
- **装飾の質感とベクター素材**: 角丸（スラブ 22px、カード 16px）、柔らかい影（不透明度 0.06〜0.12）、細い線（1〜2px）に加え、要所に専用設計のベクター装飾素材（`AST-005` ヒーロー・プリズムエンブレム、`AST-006` ステートメント引用モニュメント、`AST-007` 要点カード・コーナーファセット、`AST-008` 手順フロー・方向シェブロン）を配し、簡易ビューアーの CSS 装飾では出せない細部の質感を仕立てる（`RGH-006`）。
- **静的な紙面に限定しないライブステージ性**: イベントや講演の現場で聴衆の視線を誘導できるよう、ホバー時の繊細な質感応答、クリックによる **インタラクティブ・スポットライト**（要点カードの注目、手順ステップの進行ハイライト、STAGE バッジによるスラブ注目）、製品名「Lucivo（Luc＝光・透明 ＋ Vivo＝鮮明・躍動）」を象徴する **シグナル・ライト（図の構造に沿って上流から下流へ伝わり、届いたノードが反応する光）**、および章を 1 シーンとして全画面で見せる **ステージ発表**、発表中に全シーンを実物のまま並べる **俯瞰（ライトテーブル）**、マウスの位置に光を当てる **光のポインター** を備える（`DTP-SHOW-070`, `080`, `DTP-VTPL-090`, `DTP-LIGHT-010`〜, `DTP-SHOW-010`〜, `RGH-007`, `008`, `RGH-010`〜`012`）。方向性を持たない無秩序な背景パーティクルは読解を損なうため行わない（`RGH-903`）。
- **表紙と表も誌面として仕立てる**: 文書の最初の 1 枚は、フロントマターと章の構成から組む表紙（`DTP-VTPL-100`）とし、展示パネルの扉として何の文書かと章の地図を示す。表は格子で囲まず、横の罫線と見出しの下のアクセントの線で組み、数値の列は右揃え・等幅の数字で桁をそろえる（`DTP-VTPL-110`）。簡易ビューアーの表示が最も残りやすい扉と表に、誌面の文法を通す（`RGH-013`, `RGH-101`）。
- **記法を増やさない**: 雛形とインタラクションはすべて標準の Markdown の記述パターンから自動で有効にする。独自の記法は設けない（`FR-015` と同じ方針。`RGH-901`）。

## DTP-003 配色

雛形のアクセント色とベクター素材（`AST-005`〜`008`）の塗りは、インフォグラフィックスタイル（`FR-003`）ごとに 4 色（`--vs-c1`〜`--vs-c4`）を持ち、図の配色と同じ調子で誌面をまとめる。ブランドカラー（ダークスレート基調）は Visualモードの配色には使わない（[ブランドコンセプト](../1.SRS.md#12-ブランドコンセプトlucivo--brand-concept-sheet)）。ただし、発表の操作のための光（光のポインター、俯瞰の選択の輪。`DTP-SHOW-070`, `080`）は文書の中身ではなく Lucivo 自身の表現のため、ブランドのアクセントライト（ペールシアン・ルミナスホワイト）を使う。

- Light の 4 象限チャート（#151）: 4 つの象限を、この 4 色を白で半分に薄めた色で 1 象限ずつ塗り（右上から反時計回りに `--vs-c1`〜`c4`）、象限の違いが色で伝わるようにする。点は濃紺で、点の名前は点の右上（右端の近くでは左上）に `14px`・600 で置く。点の真下・中央に置く既定の位置は、文字が点に重なって欠けるため使わない。
- 文字に色を使うとき（カードの番号など）は、アクセント色 70% に、Light では濃紺（`#0F172A`）、Dark では白を 30% 混ぜた色（`color-mix`）にして、背景とのコントラスト比 3:1 以上（大きな太字の基準）を確保する。
- アクセント色を背景にした上の文字（手順の番号）は濃紺（`#1E293B`）とする。大きな太字（1rem 以上・800）のため、コントラスト比 3:1 以上を目安にする。
- 章番号のバッジ（`STAGE nn`）、ヒーローのプリズムエンブレム（`AST-005`）および 4 色バーも、この 4 色を使う。
- Light の図の枝の色（マインドマップ・タイムラインなど。#148）: 枝ごとの箱と線は、この 4 色を白で薄めた塗り（元の色 58%・38%・72% の 3 段。5 本目以降の枝は段を替えて区別する）にし、文字は濃紺（`#1E293B`）にする。タイムラインの箱の下線は、元の色に濃紺を 30% 混ぜた色。マインドマップの中心（主題）だけは薄めない第 1 色（`--vs-c1`）で塗り、主役を 1 つにする（塗りが暗い Circles の赤では文字を白にする）。色相を回して作る派生色（蛍光の黄緑など）は、誌面の淡い調子（ドミナント・トーン）から浮き、強調の色が多すぎて主役が分からなくなるため使わない。Dark は `DD-DIAG-025` の配色のまま。
- Light の円グラフの扇の色（#150）: 先頭の 4 枚は、この 4 色を薄めずに（濃い側のまま）不透明で塗る。5 枚目以降は白を 42% 混ぜた段、9 枚目以降は濃紺を 22% 混ぜた段にする。扇の境界は白い線（3.5px）で分ける。扇の上の文字は濃紺、暗い扇（相対輝度 0.3 未満。Circles の赤・緑など）の上だけ白にする。凡例の色見本には、塗りと同じ色相の濃い輪郭（1.5px）を付け、淡い色でも背景に溶けないようにする。淡い主色から派生した半透明の扇は、隣の扇や背景と見分けにくいため使わない。

- 図の中の文字（Visualモードのガント・タイムライン・ジャーニー。#149）: 図そのものの大きさで、ガントの作業名・区分名は `15px`（軸の日付は `12.5px`、題は `21px`・800）、タイムラインの年とイベント名は `17px`、ジャーニーの区分は `18px`・700、作業は `17px`・600 とする。Mermaid の既定（10〜13px）のままでは、図が枠の幅に合わせて縮むと文字が 10px 前後まで小さくなり、講演の投影で読めない。ガントの縦の罫線は薄く（不透明度 0.28）し、バーと文字を主役にする。ジャーニーの登場人物の丸は、スタイルの 4 色を少し沈めた色にする（既定の蛍光の黄緑を使わない）。
- ジャンプ率: 本文 1 に対し、ステートメント 1.2〜1.6、リード 1.1〜1.35。章の見出しより大きくなるのはステートメントだけで、章の主役が「その一文」であることを示す。
- 行の折り返し: ステートメントは `text-wrap: balance`、リードおよび Visualモードの段落・リスト項目・定義説明は `text-wrap: pretty` で、最後の行に 1〜2 文字だけが残る折り返しを避ける。雛形の文字（リード、カード、手順、ステートメント）は `word-break: auto-phrase` で文節の区切りで折り返し、「切り／替える」のような語の途中の改行を避ける（対応していないブラウザでは通常の折り返し）。禁則は `line-break: strict`（全体）に従う。
- 約物の詰めと数字の桁ぞろえ（`#216`）: 表紙の題名・章の見出し（`h2`）・小見出し（`h1`, `h3`〜`h6`）は `font-feature-settings: "palt" 1, "kern" 1` で句読点や括弧の前後を詰め、本文は読みやすさのため `"kern" 1` に留める。表は全体（`.exhibition-wrap table` および通常モード `table`）に `font-variant-numeric: lining-nums tabular-nums` を指定し、`.vs-num` 以外の列でも数値の桁をそろえる。
- **英語表示（`html[lang="en"]`）のタイポグラフィ（#348）**: 英文表示でも日本語表示と同じ展示品質を保つため、`html[lang="en"]` のときは以下の調整を適用し、日本語組版への影響を防ぐ。
  - **書体**: 4 スタイルの見出し書体（`Plus Jakarta Sans`、`Inter`、`M PLUS Rounded 1c`（Web 版 circles、ラテン文字サブセット含む）、`Noto Serif JP`（Web 版 editorial、ラテン文字サブセット含む））と本文書体（`Inter`）をそのまま使用する。
  - **字間（トラッキング）**: 日本語向けの広い字間を欧文向けに引き締める（`shapes`: `-0.01em`、`cards`: `-0.015em`、`circles`: `0em`、`editorial`: `0em`）。
  - **折り返しと約物**: 見出し・ステートメントの `text-wrap: balance` と段落・リードの `text-wrap: pretty` を維持しつつ、`hyphens: none` で単語途中の不自然なハイフネーションを避ける。`font-feature-settings` は `"kern" 1, "liga" 1` とする。
- 図のノードの文字（全モード。#145）: フローチャートなどのノードの文字も、文節の区切りで折り返し（`word-break: auto-phrase`）、行の長さをそろえる（`text-wrap: balance`）。「集ま／る」「書き込／む」のような語の途中の改行と、1 文字だけの最終行を作らない。先頭の番号（「1.」「4A.」）は、後に続く文字と同じ行に置く（「1.／ユーザー入力…」としない）。1 つの文節が折り返しの幅（Mermaid の既定の 120px）より長いときは、ノードを広げて 1 行に収める。Visualモードでスタイルが文字を太くするときも、太くした文字の幅でノードの大きさを決め、文字を形からはみ出させない。著者には `<br>` で改行を書かせない（Markdown をそのまま使える方針のため）。

## DTP-006 操作部の状態の示し方

アプリケーションの外枠の操作部は、「押すと何が起きるか」ではなく「今どの状態か」を示す。

- **二者択一の状態は、2 つ並びの切り替え（`.pill-container` + `.pill-btn`）で示す**: Split / Canvas / Code、高速モード / Visualモード、エディタの `閲覧` / `編集`（`FR-014`）を同じ形に揃える。今の状態のほうを選択中（`is-active`: 面の背景と影、濃い文字）にし、もう一方は淡い文字のままにする。
  - アクセント色の枠と淡い背景のボタンを、状態の表示と並べて置かない。選択中の印と見分けにくく、押す前から押した後の状態に見えるため（`閲覧` / `編集` の切り替えの以前の形「読み取り専用」＋アクセント色の「編集」ボタンで、編集中に見えた）。
  - エディタのヘッダーの切り替えは、ヘッダーの高さ（`2rem`）に収めるため、文字を `10px`、左右の余白を `9px` に詰める。
- **キーボードで選んだ位置を必ず示す（`#200`）**: `:focus-visible` で `outline: none` だけを書いて輪郭を消さない。輪郭はアクセント色（`--accent`）の `2px` の線で、背景との差 3:1 以上（WCAG 1.4.11）を保つ。受け皿として詳細度 0（`:where(:focus-visible)`）の共通の輪郭（外側 `2px`）を置き、隣と接するメニューの項目・フォルダの一覧・帯は内側（`outline-offset: -2px`）に引く。エディタは書いている間ずっと選ばれているため、内側に `--accent` を 70% に薄めた線にする。Visualモードの目次の項目は、章の色を文字色に寄せた輪郭にする。Split の境目のつまみは、アクセント色の線（`::after`）で示すため例外とする。
- **手触り（`#200`）**: メニュー（`.file-menu`）は、押したボタンの側（左のメニューは左上、右寄せのメニューは右上）を起点に、`0.16s` で不透明度 `0 → 1`・拡大 `0.96 → 1` で開く。閉じるときは即時にし、閉じかけのメニューが押されないようにする。2 つ並びの切り替え・ヘッダーのアイコンボタン・更新の確認のボタンは、押している間 `scale: 0.97` に沈ませる。動きを減らす設定（`prefers-reduced-motion`）では、どちらも動かさない。
- **選択の色とスクロールバー（`#200`）**: 選んだ文字の地は、ブラウザ既定の青をやめ、`--accent` を 26% に薄めた色（Visualモードはスタイルの `--vs-c1` を 34%）にする。スクロールバーは標準の `scrollbar-color`（つまみ `--scrollbar-thumb`: Light `#8391A6`・Dark `#64748B`、背景との差 3:1 以上。溝は透明）と `scrollbar-width: thin` で描き、非対応のブラウザだけ `::-webkit-scrollbar`（幅 `6px`）で描く。
- **効かない操作は出さない**: デザインスタイルのバー（パステル図形 / 2段カード / 5色サークル / クリームチャート）は Visualモードの配色・装飾にしか効かないため、Visualモードのときだけ表示する（`FR-003`, `#221`；トーンの切り替えを含む）。高速モードでは、その分（`36px`）だけエディタとプレビューを広げる。1024px 未満の狭い画面では、横スクロールを出さずに 360px 以上の幅で収めるため、各ラベル（「デザインスタイル:」「トーン:」「誌面:」）を隠し、スタイル 4 ボタンは選択中スタイルのアイコンと名前を出すプルダウン（`#btn-mobile-style`）に、トーンは見本の色（スウォッチ）のみに、誌面は選択中のレイアウトを示すモノラインアイコン（ページ単位 / シングルページ）に切り替える。ヘッダー右端のボタン（`#btn-open-settings`）およびモーダル（`#settings-modal`）は「その他（アプリ設定）」の位置づけとし、Markdown の整形などのアプリ設定を収容する。

## DTP-007 直接操作の手がかり（図のドラッグ、ファイルのドロップ）

操作部を増やさずに使える直接操作は、操作できる場面でだけ手がかりを出し、普段の画面を変えない。

- **図のドラッグ（`FR-038`）**: スクロール表示の図の上でだけ、カーソルを `grab`（ドラッグ中は `grabbing`）にする。収まっている図ではカーソルを変えず、動かせないものを動かせるように見せない。Ctrl + ホイールの拡大・縮小（`FR-039`）は、倍率のバッジなどをカードに足さず、図の大きさそのもので示す。Visualモードのカードのヘッダーを増やさないため。
- **ファイルのドロップ（`FR-041`）**: ファイルをドラッグしている間だけ、画面全体に受け付けの表示を重ねる。
  - 画面全体: スレートの半透明（`rgba(15, 23, 42, 0.55)`）とぼかし（`6px`）で、下の文書を沈める。
  - 中央のパネル: 濃いスレート（`rgba(15, 23, 42, 0.72)`）の角丸（`1.5rem`）に、ペールシアン（`#A5F3FC` 系）の破線の枠（`2px`）と淡い光を付ける。下向きの矢印のアイコン、「ドロップして開く」（`1.125rem`・700）、開ける拡張子（等幅・`0.75rem`）を縦に並べる。
  - 文書の中身ではなく Lucivo 自身の表現のため、発表の操作の光（`DTP-SHOW-070`）と同じく、ブランドのアクセントライトを使う（`DTP-003`）。外観（Light / Dark）とスタイルによらず、同じ見た目にする。
  - 出入りは `0.15s` のフェードと、パネルのわずかな拡大（`0.97` → `1`）にとどめる。動きを減らす設定（`prefers-reduced-motion`）では動かさない。印刷には出さない。

## DTP-008 フォルダの一覧と、開く・保存のメニュー

フォルダの一覧（`FR-044`）は、文書を主役にしたまま、同じフォルダの資料を行き来するための脇役として、エディタの左に細く置く。

- **一覧（`#folder-pane`）**: 幅 `15.5rem`。背景は `--panel-bg`、右に 1px の `--border-subtle` の線を引き、エディタの列と同じ面に並べる。
  - 見出しはエディタの見出しと同じ高さ（`2rem`）と面（`--panel-sub`）にそろえ、アクセント色のフォルダのアイコン、フォルダの名前（`11px`・700。長い名前は `…` で切る）、「フォルダを閉じる」（×）、「一覧を隠す」（«）を並べる。ボタンは `--text-muted` の線のアイコンだけにし、押せる範囲（`1.5rem` 角）に触れたときだけ面を出す。
  - サブフォルダの区切りは、等幅（JetBrains Mono）`10px`・700 の `--text-muted` で `docs/sub/` のようにパスを示す。ファイルは、ファイルのアイコンと名前（`12px`、`--text-secondary`）で並べる。
  - 開いているファイルは、操作部の選択中の示し方（`DTP-006`）に合わせ、淡いアクセントの面（`--accent-soft`）、濃い文字（`--text-primary`・700）、左端の 3px のアクセントの線で示す。アイコンもアクセント色にする。
- **隠したとき（`#btn-folder-show`）**: 幅 `1.75rem` の帯だけを残し、フォルダのアイコンと開く向きの矢印（»）を縦に並べる。面は `--panel-sub`。触れたときはアイコンをアクセント色にする。
- **狭い画面（幅 1024px 未満）**: 一覧はエディタとプレビューの上に重ね、右側に影を付けて浮かせる。隠したときは、帯の代わりに、左下に影を付けた丸いボタン（`2.75rem`）を浮かせる。エディタの見出しに重ねないため。
- **出さない場面**: ステージ発表と印刷。
- **開く・保存のメニュー（`FR-043`）**: 「開く」「保存」のボタンは、どちらも同じ形（`2rem` の高さ、`--panel-sub` の面、線のアイコン＋文字）にして対に見せる。メニューの見た目は従来のファイルメニュー（`.file-menu`）と同じにする。保存メニューの「Markdown を保存」には、保存するファイル名を括弧で添え、何が保存されるかを押す前に示す。

## DTP-009 フォルダ構成のツリー

フォルダ構成（`FR-047`）は、コードブロックと同じ面に置き、罫線の文字の代わりに、細い線で階層を示す。

- **面**: 背景 `--panel-sub`、1px の `--border-strong` の枠、角丸 `10px`。コードブロック（`DD-MD-015`）と同じ面にして、本文と区別する。Visualモードでは、カードの面に寄せた背景と淡い影にして、誌面のカードと調子をそろえる。
- **線**: 1 段 `1.35rem`、線は `1.5px`、色は `--text-muted` を 55% にした淡い色。最後の子の角は小さく丸める。行の高さ（`1.75rem`）を詰め、縦線を途切れさせない。
- **アイコン**: フォルダだけを塗りのアイコンにし、アクセント色（Visualモードは、スタイルの 1 色目を 80% にした色）にする。ファイルは線のアイコンで `--text-muted` にし、文書・画像・コード・そのほかを形で見分ける。色を増やさず、構造（フォルダ）だけが目に入るようにする。
- **文字**: 名前は等幅（JetBrains Mono）`0.78rem`、根は太字。注釈は本文の書体で `--text-secondary`、名前の列から `2.5rem` 離した列にそろえる。省略の行（`...`）はアイコンを出さず淡くする。

## DTP-010 SNS で共有したときの画像（OGP）

Web 版の言語別のページ（`/ja/`・`/en/`、`FR-065`）を SNS やチャットで共有したときに出る画像（`og:image`）を、`AST-147` とする。

- **大きさと形式**: `1200×630` の PNG。多くの SNS は SVG を OGP の画像として扱わないため、ロゴの SVG（`AST-010`〜`012`）は使わない。
- **文字を入れない**: 画像の中に文字を入れず、日本語版・英語版で同じ画像を使う。製品名と説明は、`og:title`・`og:description` が画像の外に出す。ロゴのワードマーク（`Lucivo`）も入れず、記号（LV のモノグラム）だけを使う。
- **構図**: 中央に LV のモノグラムを大きく置き、左右に、奥へ並ぶ展示パネル（誌面・円グラフ・棒グラフ・図のノードを、文字なしの図形で表す）を置く。展示室の床の反射と、斜めに差し込む光で、「暗転した会場で、文書が展示品として浮かぶ」場面を表す（[ブランドコンセプト](../1.SRS.md#12-ブランドコンセプトlucivo--brand-concept-sheet)、[製品名称コンセプト仕様書](product-name-concept.md)）。
- **配色**: 地はオブシディアンブラック〜ディープスレート（`#05070d`〜`#111c33`）、光はルミナスシアン（`#00f0ff`・`#38bdf8`）。下端に、シアンの細い帯を置く。
- **切り抜きへの備え**: SNS によっては中央を正方形や細長く切り抜くため、主役のモノグラムを中央に置き、端の展示パネルは欠けても成り立つ脇役にする。
- **作り方**: 作図元 [assets/sources/ogp-image.svg](assets/sources/ogp-image.svg) を、`tools/build-ogp-image.cjs` で PNG（`public/assets/ogp/lucivo-ogp.png`）に書き出してコミットする。小さな円に光彩（`feGaussianBlur`）を掛けるときは、フィルターの範囲を広く取る（狭いと、ぼかしが四角く切れる）。
