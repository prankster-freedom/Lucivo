# 75. 黄昏のアイリス（Twilight Iris）

- **ID**: `twilight-iris`
- **トーン区分**: やわらかい＋こい（soft + deep）
- **配色技法**: グラデーション（青から紫へ、色相を少しずつ変える）
- **基にした配色**: `#55447F`（ディープバイオレット）、`#808CC5`（ペリウィンクル）、`#BE80B6`（オーキッド）、`#96BCD7`（ライトブルー）
- **印象・用途**: 黄昏の空とアイリス。幻想的で静かな、物語・音楽向け。
