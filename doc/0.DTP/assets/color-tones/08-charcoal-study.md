# 08. 炭とインクの書斎（Charcoal Study）

- **ID**: `charcoal-study`
- **トーン区分**: くらいはいみ（dark grayish）
- **配色技法**: セパレーション（深い無彩色で色相を区切る）
- **印象・用途**: 万年筆のインクと墨のようなストイックさ。コード解説・技術仕様・アーキテクチャ図向け。
