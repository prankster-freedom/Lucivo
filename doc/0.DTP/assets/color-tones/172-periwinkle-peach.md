# 172. ペリウィンクルと桃（Periwinkle Peach）

- **ID**: `periwinkle-peach`
- **トーン区分**: ごくうすい＋うすい（very pale + pale）
- **配色技法**: 色相配色（ペリウィンクルと桃色の補色寄りを、淡いトーンで）
- **基にした配色**: `#B9C3E4`（ペリウィンクル）、`#F8CEC1`（桃色）、`#FEF4EE`（白）
- **印象・用途**: 夕方の窓辺。穏やかで温かな、暮らし・エッセイ向け。
