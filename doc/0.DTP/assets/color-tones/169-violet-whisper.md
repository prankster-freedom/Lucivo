# 169. 菫のささやき（Violet Whisper）

- **ID**: `violet-whisper`
- **トーン区分**: ごくうすい＋こい（very pale + deep）
- **配色技法**: トーン・オン・トーン（青紫の色相で、白から菫まで明度を大きく変える）
- **基にした配色**: `#6D61A8`（菫）、`#D3DAF0`（ラベンダー）、`#F1EDF7`（白）
- **印象・用途**: 静かな菫の花。凛として上品な、式典・案内向け。
