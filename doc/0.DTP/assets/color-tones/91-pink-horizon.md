# 91. 桃色の地平（Pink Horizon）

- **ID**: `pink-horizon`
- **トーン区分**: うすい（pale）
- **配色技法**: 色相配色（淡い青を主役に、淡いピンクを対比させる）
- **基にした配色**: `#A5CEEF`（ブルー）、`#FAD2DB`（ピンク）、`#CDE4F1`（淡い青）、`#F5EFE9`（オフホワイト）
- **印象・用途**: 夢の中の水平線。軽やかで詩的な、エッセイ・ブランドストーリー向け。
