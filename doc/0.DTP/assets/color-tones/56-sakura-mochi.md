# 56. 桜餅（Sakura Mochi）

- **ID**: `sakura-mochi`
- **トーン区分**: うすい（pale）
- **配色技法**: ドミナント・カラー（赤みのピンクでそろえる）
- **基にした配色**: `#F5B5D1`（ピンク）、`#F9CAC3`（サーモンピンク）
- **印象・用途**: 春の和菓子。可愛らしく華やかな、季節の行事・和の話題向け。
