# 130. シダの森（Fern Forest）

- **ID**: `fern-forest`
- **トーン区分**: あかるい＋くらい（bright + dark）
- **配色技法**: ナチュラルハーモニー（明るい黄緑を光に、紺と青灰を陰にする）
- **基にした配色**: `#162A41`（紺）、`#C7D882`（黄緑）、`#90A7B0`（青灰）、`#F5EFE9`（オフホワイト）
- **印象・用途**: 木漏れ日のシダの森。清々しく奥行きのある、自然・環境の話題向け。
