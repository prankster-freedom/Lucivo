# 193. 入江の夕陽（Lagoon Sunset）

- **ID**: `lagoon-sunset`
- **トーン区分**: つよい＋うすい（strong + pale）
- **配色技法**: 色相配色（青緑とオレンジの補色を、淡い桃色でつなぐ）
- **基にした配色**: `#13969E`（青緑）、`#F9AF3C`（オレンジ）、`#FBE4D7`（桃色）
- **印象・用途**: 夕暮れの入江。懐かしく爽やかな、旅行・レジャー向け。
