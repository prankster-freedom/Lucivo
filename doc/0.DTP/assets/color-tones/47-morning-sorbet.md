# 47. 朝のシャーベット（Morning Sorbet）

- **ID**: `morning-sorbet`
- **トーン区分**: ごくうすい＋うすい（very pale + pale）
- **配色技法**: ドミナント・トーン（暖色のごく淡いトーンでそろえる）
- **基にした配色**: `#F9BD8F`（アプリコット）、`#FFEDA8`（レモン）、`#F8DDDE`（ピンク）、`#FEF4EE`（白）
- **印象・用途**: 朝の光とシャーベット。軽やかで幸福な、子ども・ギフトの話題向け。
