# 112. 雷雲の空（Thunder Sky）

- **ID**: `thunder-sky`
- **トーン区分**: ごくうすい＋くらい（very pale + dark）
- **配色技法**: トーン配色（青灰の色相に絞り、白から炭色まで明度の差でまとめる）
- **基にした配色**: `#3E3C41`（炭）、`#B7CCDB`（青灰）、`#E1E7EE`（淡い青灰）、`#F1F1F3`（白）
- **印象・用途**: 雷の前の空。静かな緊張感のある、技術・分析の資料向け。
