# 04. 植物標本と乾いた紙（Botanical Herbarium）

- **ID**: `botanical-herbarium`
- **トーン区分**: やわらかい（soft）
- **配色技法**: ナチュラルハーモニー（黄寄りを明るく、青紫寄りを落ち着かせる）
- **印象・用途**: 押し花や図鑑のような親しみと上品さ。プロダクト紹介・教育資料・読み物向け。
