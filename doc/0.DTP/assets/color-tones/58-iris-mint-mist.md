# 58. 菖蒲と薄荷の霧（Iris Mint Mist）

- **ID**: `iris-mint-mist`
- **トーン区分**: ごくうすい（very pale）
- **配色技法**: グラデーション（紫・青・青緑へ、色相を少しずつ変える）
- **基にした配色**: `#E7C6DE`（ライラック）、`#D3DDF1`（ペリウィンクル）、`#CCE7E3`（ミント）
- **印象・用途**: 朝霧の水辺。静かで澄んだ、ウェルネス・瞑想の話題向け。
