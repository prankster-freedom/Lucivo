# 90. パステルの雲（Pastel Cloud）

- **ID**: `pastel-cloud`
- **トーン区分**: ごくうすい（very pale）
- **配色技法**: ドミナント・トーン（4 つの色相を、ごく淡いトーンでそろえる）
- **基にした配色**: `#C0C6E5`（ラベンダー）、`#FAD2DB`（ピンク）、`#DFEFE4`（ミント）、`#D3E0F2`（ペリウィンクル）
- **印象・用途**: 綿菓子のような雲。やさしく軽やかな、子ども・ギフト向け。
