# 128. 観葉植物のアトリエ（Botanical Studio）

- **ID**: `botanical-studio`
- **トーン区分**: にぶい＋あかるい（dull + bright）
- **配色技法**: 色相配色（深い青緑とペリウィンクルに、オレンジを対比させる）
- **基にした配色**: `#4C716E`（深い青緑）、`#F6AA6C`（オレンジ）、`#6884C1`（ペリウィンクル）、`#FDEADF`（白）
- **印象・用途**: 植物のある仕事場。穏やかで誠実な、ウェルビーイング・働き方の話題向け。
