# 101. 流木とティール（Driftwood Teal）

- **ID**: `driftwood-teal`
- **トーン区分**: にぶい＋うすい（dull + pale）
- **配色技法**: 色相配色（ティールと杏の補色を、灰緑と白で落ち着かせる）
- **基にした配色**: `#4D8F8D`（ティール）、`#EFC99C`（杏）、`#61716C`（灰緑）、`#EFEEF0`（白）
- **印象・用途**: 晴れた日の作業小屋。誠実で親しみやすい、ものづくり・地域の話題向け。
