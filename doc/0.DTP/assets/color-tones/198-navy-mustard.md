# 198. ネイビーとマスタード（Navy Mustard）

- **ID**: `navy-mustard`
- **トーン区分**: くらい＋あかるい（dark + bright）
- **配色技法**: 色相配色（ネイビーと黄・杏の補色を、クリームでつなぐ）
- **基にした配色**: `#435272`（ネイビー）、`#FBC96C`（杏）、`#E6D46F`（マスタード）、`#F9E9D1`（クリーム）
- **印象・用途**: レトロな制服。端正で懐かしい、教育・ブランド向け。
