# 199. レトロな旅（Retro Travel）

- **ID**: `retro-travel`
- **トーン区分**: つよい＋あかるいはいみ（strong + light grayish）
- **配色技法**: 色相配色（青と黄土の補色を、スレートとグレージュでまとめる）
- **基にした配色**: `#1396BE`（ブルー）、`#E0B37A`（黄土）、`#5F707E`（スレート）、`#E5DFD8`（グレージュ）
- **印象・用途**: 古い旅行かばん。懐かしく落ち着いた、旅行・カルチャー向け。
