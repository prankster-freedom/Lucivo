# 20. 分光プリズムと黒曜石（Cyber Prism）

- **ID**: `cyber-prism`
- **トーン区分**: あかるい＋くらい（bright + dark）
- **配色技法**: コンプレックスハーモニー（暗い無彩色と発光する分光の対比）
- **印象・用途**: Lucivo の「光と透明」を先端的に見せるコントラスト。技術ショーケース・製品デモ向け。
