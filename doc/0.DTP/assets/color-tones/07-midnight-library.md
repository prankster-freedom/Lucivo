# 07. 夜を編む図書館（Midnight Library）

- **ID**: `midnight-library`
- **トーン区分**: くらい（dark）
- **配色技法**: ナチュラルハーモニー（深い彩りの中に灯る金と藍）
- **印象・用途**: 深夜の書庫や創作企画に寄り添う重厚な知性。暗所でのステージ発表・物語企画向け。
