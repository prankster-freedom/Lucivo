# 40. フラミンゴのラグーン（Flamingo Lagoon）

- **ID**: `flamingo-lagoon`
- **トーン区分**: あかるい＋うすい（bright + pale）
- **配色技法**: 色相配色（赤ピンクと青緑の補色を、明るいトーンで）
- **基にした配色**: `#EB5B44`（レッド）、`#70C4C0`（ティール）、`#EF85B0`（ピンク）、`#D8ECE9`（ミント）
- **印象・用途**: 南国の干潟とフラミンゴ。華やかで涼しげな、旅行・リゾートの話題向け。
