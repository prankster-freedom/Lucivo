# 98. ライムとシアン（Lime Cyan）

- **ID**: `lime-cyan`
- **トーン区分**: さえた（vivid）
- **配色技法**: 色相配色（鮮やかなライムとシアンの類似寄りの対比）
- **基にした配色**: `#05A5D2`（シアン）、`#E5E460`（ライム）
- **印象・用途**: 夏のスポーツ。軽快でエネルギッシュな、スポーツ・アウトドア向け。
