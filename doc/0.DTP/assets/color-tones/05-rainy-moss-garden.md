# 05. 雨上がりの苔庭（Rainy Moss Garden）

- **ID**: `rainy-moss-garden`
- **トーン区分**: にぶい（dull）
- **配色技法**: ドミナント・トーン（中明度・中低彩度のしっとりした調和）
- **印象・用途**: 湿り気を帯びた静けさと重厚感。長期ロードマップ・振り返り・技術記事向け。
