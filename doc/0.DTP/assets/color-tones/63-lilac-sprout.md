# 63. ライラックと新芽（Lilac Sprout）

- **ID**: `lilac-sprout`
- **トーン区分**: ごくうすい（very pale）
- **配色技法**: 色相配色（紫と黄緑の補色を、ごく淡いトーンで）
- **基にした配色**: `#E7C6DE`（ライラック）、`#DAE8C1`（新芽）
- **印象・用途**: 春先の庭。やさしく初々しい、新生活・入学の話題向け。
