# 144. 海風（Ocean Breeze）

- **ID**: `ocean-breeze`
- **トーン区分**: こい＋うすい（deep + pale）
- **配色技法**: グラデーション（インディゴからティール、淡い水色へ寒色を少しずつ変える）
- **基にした配色**: `#354093`（インディゴ）、`#77C8D0`（ティール）、`#C2E6F9`（淡い水色）、`#E7F3EA`（ミントホワイト）
- **印象・用途**: 海から吹く風。清々しく開放的な、旅行・テクノロジー向け。
