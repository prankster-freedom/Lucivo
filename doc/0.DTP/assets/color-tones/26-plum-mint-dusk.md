# 26. プラムと薄荷の夕べ（Plum Mint Dusk）

- **ID**: `plum-mint-dusk`
- **トーン区分**: あかるいはいみ＋くらいはいみ（light grayish + dark grayish）
- **配色技法**: ドミナント・トーン（灰みのトーンでそろえ、暗いプラムで締める）
- **基にした配色**: `#E7F3EA`（ミントホワイト）、`#E7D4AD`（砂）、`#C0C1C4`（グレー）、`#77666A`（プラム）
- **印象・用途**: 日暮れの庭。しっとりと大人びた、レポート・展示の解説向け。
