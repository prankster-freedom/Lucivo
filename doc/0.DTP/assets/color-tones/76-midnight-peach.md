# 76. 真夜中の桃（Midnight Peach）

- **ID**: `midnight-peach`
- **トーン区分**: うすい＋くらい（pale + dark）
- **配色技法**: 色相配色（暗い紺とティールに、ピーチとライラックの淡色を合わせる）
- **基にした配色**: `#312A47`（ミッドナイト）、`#3C757E`（ティール）、`#F9C5B1`（ピーチ）、`#DACFE6`（ライラック）
- **印象・用途**: 夜更けのカフェ。落ち着きとぬくもりのある、トーク・対談の資料向け。
