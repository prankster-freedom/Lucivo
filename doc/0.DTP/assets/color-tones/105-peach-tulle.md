# 105. 桃色のチュール（Peach Tulle）

- **ID**: `peach-tulle`
- **トーン区分**: うすい＋こい（pale + deep）
- **配色技法**: アクセントカラー（淡いピンクと白の地に、テラコッタとワインを差す）
- **基にした配色**: `#DA8164`（テラコッタ）、`#7B3341`（ワイン）、`#F7BFC5`（ピンク）、`#FDEADF`（白）
- **印象・用途**: チュールのドレス。可憐で温かな、ウェディング・ファッション向け。
