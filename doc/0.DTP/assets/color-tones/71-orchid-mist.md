# 71. 霧の中の蘭（Orchid Mist）

- **ID**: `orchid-mist`
- **トーン区分**: やわらかい＋ごくうすい（soft + very pale）
- **配色技法**: 色相配色（赤紫のオーキッドと、青みのペリウィンクルを組み合わせる）
- **基にした配色**: `#CE88BA`（オーキッド）、`#D3DDF1`（ペリウィンクル）
- **印象・用途**: 霧の中の蘭。優美で幻想的な、美容・アート向け。
