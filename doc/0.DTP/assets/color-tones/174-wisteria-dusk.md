# 174. 藤の夕べ（Wisteria Dusk）

- **ID**: `wisteria-dusk`
- **トーン区分**: ごくうすい＋こい（very pale + deep）
- **配色技法**: グラデーション（桃色の白から、藤色・紫・菫へ少しずつ深める）
- **基にした配色**: `#624F8F`（菫）、`#A788BE`（藤）、`#B9C3E4`（ペリウィンクル）、`#FDEAE3`（白）
- **印象・用途**: 夕暮れの藤棚。優雅で奥ゆかしい、文化・式典向け。
