# 136. 入江と紺（Lagoon Navy）

- **ID**: `lagoon-navy`
- **トーン区分**: こい＋うすい（deep + pale）
- **配色技法**: トーン配色（青緑の色相に絞り、ミントから紺まで明度を変える）
- **基にした配色**: `#4D8F8D`（ティール）、`#355469`（紺）、`#ACD9D4`（ミント）、`#EEEDEE`（白）
- **印象・用途**: 深い入江。澄んで誠実な、医療・研究の話題向け。
