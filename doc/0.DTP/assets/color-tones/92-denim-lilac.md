# 92. デニムとライラック（Denim Lilac）

- **ID**: `denim-lilac`
- **トーン区分**: うすい＋つよい（pale + strong）
- **配色技法**: クールシェード（青みの淡色でそろえ、デニムの青で締める）
- **基にした配色**: `#4E6DB3`（デニム）、`#9FD6E0`（アクア）、`#CECAE6`（ラベンダー）、`#DBE7F2`（淡い青）
- **印象・用途**: 洗いざらしのデニム。爽やかで気取らない、ファッション・暮らし向け。
