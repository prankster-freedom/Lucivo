# 62. 麻と砂（Linen Sand）

- **ID**: `linen-sand`
- **トーン区分**: ごくうすい＋あかるいはいみ（very pale + light grayish）
- **配色技法**: ドミナント・カラー（黄みの淡い色相でそろえる）
- **基にした配色**: `#E0CDAB`（サンド）、`#FDEADF`（白）
- **印象・用途**: 麻のシーツと浜の砂。ナチュラルで静かな、ホテル・暮らしの話題向け。
