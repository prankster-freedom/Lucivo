# 178. 陶器の手（Ceramic Hands）

- **ID**: `ceramic-hands`
- **トーン区分**: さえた＋くらい（vivid + dark）
- **配色技法**: 色相配色（赤と青の補色を、白い陶器の灰と黒で引き締める）
- **基にした配色**: `#E84243`（レッド）、`#3E79BD`（ブルー）、`#29231E`（黒）、`#ECEAE8`（陶器の白）
- **印象・用途**: 釉薬をかけた陶器。力強く現代的な、クラフト・アート向け。
