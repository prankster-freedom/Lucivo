# 102. 青いシャツとスレート（Oxford Shirt）

- **ID**: `oxford-shirt`
- **トーン区分**: うすい＋くらいはいみ（pale + dark grayish）
- **配色技法**: トーン配色（青の色相に絞り、明度の差でまとめる）
- **基にした配色**: `#586174`（スレート）、`#8598B7`（ブルーグレー）、`#C4DBF2`（淡い青）、`#F0F0F1`（白）
- **印象・用途**: 洗いたてのオックスフォードシャツ。清潔で信頼感のある、ビジネス・報告向け。
