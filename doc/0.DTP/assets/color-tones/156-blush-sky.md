# 156. 頬紅と空（Blush Sky）

- **ID**: `blush-sky`
- **トーン区分**: ごくうすい＋うすい（very pale + pale）
- **配色技法**: 色相配色（淡いピンクと水色の補色を、ごく淡いトーンで）
- **基にした配色**: `#F9CAC4`（サーモンピンク）、`#CFE8FA`（水色）、`#FDEFF4`（ピンク）
- **印象・用途**: 春の空と桜。やさしく明るい、季節の案内・子ども向け。
