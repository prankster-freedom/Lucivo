# 44. 真夏のカーニバル（Carnival Night）

- **ID**: `carnival-night`
- **トーン区分**: さえた＋こい（vivid + deep）
- **配色技法**: 色相配色（マゼンタ・オレンジ・ライムの鮮やかな対比を、深い紫で締める）
- **基にした配色**: `#E72385`（マゼンタ）、`#EF7748`（オレンジ）、`#5B2F68`（パープル）、`#DFDD19`（ライム）
- **印象・用途**: 熱気あふれるカーニバル。祝祭感のある、フェス・エンタメ向け。
