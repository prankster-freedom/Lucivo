# 177. コバルトとみかん（Cobalt Tangerine）

- **ID**: `cobalt-tangerine`
- **トーン区分**: つよい＋ごくうすい（strong + very pale）
- **配色技法**: 色相配色（コバルトとオレンジの補色を、淡い青白の地に置く）
- **基にした配色**: `#396AB2`（コバルト）、`#F18448`（オレンジ）、`#6A61A8`（菫）、`#E9EFF4`（青白）
- **印象・用途**: 抽象的な線画。大胆でモダンな、アート・ブランド向け。
