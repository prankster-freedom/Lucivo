# 106. ドライローズ（Dried Rose）

- **ID**: `dried-rose`
- **トーン区分**: あかるいはいみ＋くらい（light grayish + dark）
- **配色技法**: アクセントカラー（くすんだローズの地に、琥珀とワインを少し）
- **基にした配色**: `#CA9790`（ダスティローズ）、`#D68942`（琥珀）、`#7B3341`（ワイン）、`#F7E3E1`（ブラッシュ）
- **印象・用途**: 乾いた薔薇とリネン。懐かしく上品な、ライフスタイル・ブランド向け。
