# 95. 杏とプール（Apricot Pool）

- **ID**: `apricot-pool`
- **トーン区分**: あかるい＋うすい（bright + pale）
- **配色技法**: 色相配色（杏と水色の補色を、淡い黄でつなぐ）
- **基にした配色**: `#FBC96C`（杏）、`#9ED5DB`（アクア）、`#F8EF8A`（淡い黄）
- **印象・用途**: 夏休みのプール。明るく楽しい、子ども・レジャー向け。
