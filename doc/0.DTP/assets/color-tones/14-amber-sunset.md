# 14. 琥珀の夕暮れ（Amber Sunset）

- **ID**: `amber-sunset`
- **トーン区分**: やわらかい〜にぶい（soft / dull）
- **配色技法**: グラデーション＋ウォームシェード（黄金→朱→茜→暮紫）
- **印象・用途**: 日光の温もりと時間の移ろい。振り返り・ロードマップ・エモーショナルな提案書向け。
