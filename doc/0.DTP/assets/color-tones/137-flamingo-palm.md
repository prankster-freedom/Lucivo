# 137. フラミンゴとヤシ（Flamingo Palm）

- **ID**: `flamingo-palm`
- **トーン区分**: さえた＋ごくうすい（vivid + very pale）
- **配色技法**: 色相配色（黄・ピンク・コーラルの鮮やかな暖色を、淡い青白の地に置く）
- **基にした配色**: `#EC619F`（ピンク）、`#FFDD23`（イエロー）、`#EC644E`（コーラル）、`#E8EEF7`（淡い青白）
- **印象・用途**: 南国の切り絵。陽気でにぎやかな、夏のイベント・キャンペーン向け。
