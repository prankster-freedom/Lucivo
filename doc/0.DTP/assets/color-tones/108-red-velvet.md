# 108. 赤いベルベット（Red Velvet）

- **ID**: `red-velvet`
- **トーン区分**: つよい＋うすい（strong + pale）
- **配色技法**: トーン・オン・トーン（赤の色相で、淡いピンクから暗いバーガンディまで明度を変える）
- **基にした配色**: `#CC4133`（レッド）、`#7C1623`（バーガンディ）、`#F9CAC4`（ピンク）
- **印象・用途**: 赤いベルベットのケーキ。華やかで格調のある、お祝い・式典向け。
