# 43. 向日葵の港（Sunflower Harbor）

- **ID**: `sunflower-harbor`
- **トーン区分**: さえた＋こい（vivid + deep）
- **配色技法**: 色相配色（黄と青の補色を、深いティールとオーカーで支える）
- **基にした配色**: `#05A5D2`（シアン）、`#F4E100`（イエロー）、`#3A737D`（ディープティール）、`#D79327`（オーカー）
- **印象・用途**: 夏の港と向日葵畑。力強く明快な、産業・観光の紹介向け。
