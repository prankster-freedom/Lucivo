# 41. 苺とライムのソーダ（Strawberry Lime）

- **ID**: `strawberry-lime`
- **トーン区分**: さえた＋うすい（vivid + pale）
- **配色技法**: アクセントカラー（鮮やかな赤を主役に、淡いピンクとライムを添える）
- **基にした配色**: `#E84130`（レッド）、`#F5B7D4`（ピンク）、`#D6E18D`（ライム）
- **印象・用途**: 苺とライムの炭酸。はつらつとした、飲食・セールの告知向け。
