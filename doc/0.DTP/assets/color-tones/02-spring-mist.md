# 02. 春霞のさくら（Spring Mist）

- **ID**: `spring-mist`
- **トーン区分**: うすい（pale）
- **配色技法**: カマイユ／ドミナント・トーン（高明度・低彩度の淡い余白）
- **印象・用途**: 白い紙面にほのかに色が滲むような繊細さ。エッセイ・世界観紹介・余白重視の誌面向け。
