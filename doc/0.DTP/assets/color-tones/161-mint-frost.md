# 161. 薄荷と霜（Mint Frost）

- **ID**: `mint-frost`
- **トーン区分**: ごくうすい（very pale）
- **配色技法**: カマイユ（ミントと氷色の、ごくわずかな差）
- **基にした配色**: `#E7F3EA`（ミント）、`#EEF8FE`（氷）
- **印象・用途**: 霜の降りた朝。澄んで清潔な、医療・ウェルネス向け。
