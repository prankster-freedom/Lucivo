# 78. インクと便箋（Ink Cream）

- **ID**: `ink-cream`
- **トーン区分**: あかるい＋くらいはいみ（bright + dark grayish）
- **配色技法**: ナチュラルハーモニー（黄みのクリームを明るく、青を暗くする）
- **基にした配色**: `#39536F`（インディゴ）、`#78ACD7`（ブルー）、`#EBEACF`（クリーム）
- **印象・用途**: 万年筆と便箋。誠実で落ち着いた、文書・報告向け。
