# 80. 夜会のドレス（Magenta Plum）

- **ID**: `magenta-plum`
- **トーン区分**: つよい＋くらい（strong + dark）
- **配色技法**: トーン・オン・トーン（赤紫の色相で、明度を大きく変える）
- **基にした配色**: `#BF589C`（マゼンタ）、`#522B3D`（プラム）
- **印象・用途**: 夜会のドレス。艶やかで劇的な、エンタメ・ショー向け。
