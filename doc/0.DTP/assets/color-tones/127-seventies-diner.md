# 127. 70 年代のダイナー（Seventies Diner）

- **ID**: `seventies-diner`
- **トーン区分**: つよい＋あかるいはいみ（strong + light grayish）
- **配色技法**: 色相配色（赤とマスタードの暖色に、灰みの青緑を合わせる）
- **基にした配色**: `#D83C2D`（赤）、`#E9A431`（マスタード）、`#B3CFCD`（セージ）、`#F9E9D1`（クリーム）
- **印象・用途**: レトロなダイナー。陽気で人懐こい、飲食・イベント向け。
