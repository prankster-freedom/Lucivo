# 96. 菫と頬紅（Violet Blush）

- **ID**: `violet-blush`
- **トーン区分**: うすい＋こい（pale + deep）
- **配色技法**: アクセントカラー（淡いライラックとピンクの地に、深い菫色を差す）
- **基にした配色**: `#624F8F`（菫）、`#DFC5E0`（ライラック）、`#FAD2DB`（ピンク）
- **印象・用途**: 菫の花束。可憐で品のある、お祝い・ギフト向け。
