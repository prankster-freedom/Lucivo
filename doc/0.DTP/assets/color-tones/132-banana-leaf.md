# 132. バナナの葉（Banana Leaf）

- **ID**: `banana-leaf`
- **トーン区分**: つよい＋くらい（strong + dark）
- **配色技法**: ナチュラルハーモニー（明るい黄緑を主役に、青と紺を陰にする）
- **基にした配色**: `#B9C965`（黄緑）、`#162A41`（紺）、`#588194`（スチールブルー）、`#D6E4E7`（淡い青）
- **印象・用途**: 南国の大きな葉。生命力のある、サステナビリティ・自然の話題向け。
