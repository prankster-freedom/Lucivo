# 18. 北欧の霜柱（Nordic Frost）

- **ID**: `nordic-frost`
- **トーン区分**: うすい〜あかるいはいみ（pale / light grayish）
- **配色技法**: クールシェード（氷・すりガラス・冬の空気を思わせる寒色統一）
- **印象・用途**: 澄み切った透明感とミニマルな静謐さ。ドキュメント規約・API 仕様・医療/科学資料向け。
