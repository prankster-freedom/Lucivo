# 50. 薔薇の花びら（Rose Petal）

- **ID**: `rose-petal`
- **トーン区分**: うすい（pale）
- **配色技法**: トーン・オン・トーン（同じ赤みの色相で明度を変える）
- **基にした配色**: `#F8C1B8`（サーモン）、`#FCE0DE`（淡いピンク）
- **印象・用途**: 薔薇の花びら。可憐でやさしい、お祝い・招待状向け。
