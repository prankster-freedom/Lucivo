# 12. 深夜の電脳祭（Neon Arcade）

- **ID**: `neon-arcade`
- **トーン区分**: さえた（vivid）
- **配色技法**: コンプレックスハーモニー（鮮やかな原色と深い闇の対比）
- **印象・用途**: 圧倒的な視認性とエネルギー。ハッカソン・ライブデモ・ナイトイベント向け。
