# 52. 桃の花（Peach Blossom）

- **ID**: `peach-blossom`
- **トーン区分**: うすい＋ごくうすい（pale + very pale）
- **配色技法**: カマイユ（赤みのごく淡い 3 色を、さりげなく変える）
- **基にした配色**: `#F8C1B8`（サーモン）、`#FCE0DE`（淡いピンク）、`#FEECD9`（クリーム）
- **印象・用途**: 春の桃の花。上品で柔らかな、季節の挨拶・案内向け。
