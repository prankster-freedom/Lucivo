# 88. 真夜中のライム（Midnight Lime）

- **ID**: `midnight-lime`
- **トーン区分**: くらい＋うすい（dark + pale）
- **配色技法**: 色相配色（深い青紫と、淡いライムの補色の対比）
- **基にした配色**: `#EAE880`（ライム）、`#312A47`（ミッドナイト）
- **印象・用途**: 夜のネオンサイン。鋭く現代的な、テクノロジー・スタートアップ向け。
