# 82. 紫のベルベット（Violet Velvet）

- **ID**: `violet-velvet`
- **トーン区分**: こい＋やわらかい（deep + soft）
- **配色技法**: トーン・オン・トーン（青紫の色相で、明度を変える）
- **基にした配色**: `#432D7F`（バイオレット）、`#808CC5`（ペリウィンクル）
- **印象・用途**: ベルベットの幕。気品のある、式典・発表会向け。
