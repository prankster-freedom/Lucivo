# 03. 生成りのアトリエ（Linen Atelier）

- **ID**: `linen-atelier`
- **トーン区分**: あかるいはいみ（light grayish）
- **配色技法**: トーン・オン・トーン（無彩色寄りの穏やかな明度差）
- **印象・用途**: 麻布や上質紙のような落ち着いた知的さ。デザイン仕様書・建築・クラフト解説向け。
