# 175. 天使の羽（Angel Wing）

- **ID**: `angel-wing`
- **トーン区分**: ごくうすい（very pale）
- **配色技法**: カマイユ（水色・ライラック・ピンクを、白の地にさりげなく置く）
- **基にした配色**: `#CFE8FA`（水色）、`#DFC5E0`（ライラック）、`#F9DFEC`（ピンク）、`#FDF7F8`（白）
- **印象・用途**: ふわりと舞う羽。清らかで夢のある、ウェディング・ギフト向け。
