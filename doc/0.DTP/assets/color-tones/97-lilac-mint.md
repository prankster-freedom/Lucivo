# 97. ライラックとミント（Lilac Mint）

- **ID**: `lilac-mint`
- **トーン区分**: ごくうすい（very pale）
- **配色技法**: 色相配色（紫と青緑の、ごく淡いトーンでの組み合わせ）
- **基にした配色**: `#DFC5E0`（ライラック）、`#C1E1D2`（ミント）
- **印象・用途**: 春の朝の庭。やわらかく清らかな、ウェルネス・美容向け。
