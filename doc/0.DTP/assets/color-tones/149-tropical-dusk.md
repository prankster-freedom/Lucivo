# 149. 南国の夕暮れ（Tropical Dusk）

- **ID**: `tropical-dusk`
- **トーン区分**: さえた＋こい（vivid + deep）
- **配色技法**: 色相配色（オレンジとピンクの暖色を、深い紫で締め、ミントで和らげる）
- **基にした配色**: `#F5A04E`（オレンジ）、`#D65A9C`（ピンク）、`#432D7F`（深い紫）、`#CCE7E3`（ミント）
- **印象・用途**: 南国の夕暮れ。情熱的で開放的な、リゾート・エンタメ向け。
