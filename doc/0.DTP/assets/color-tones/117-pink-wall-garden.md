# 117. 桃色の壁と庭（Pink Wall Garden）

- **ID**: `pink-wall-garden`
- **トーン区分**: つよい＋こい（strong + deep）
- **配色技法**: 色相配色（桃色の地に、オレンジと深い緑の補色を合わせる）
- **基にした配色**: `#DB8749`（オレンジ）、`#00613A`（深緑）、`#C5C54E`（オリーブ）、`#F8CEC1`（桃色）
- **印象・用途**: 南欧の桃色の壁と植物。陽気で味わいのある、旅行・暮らし向け。
