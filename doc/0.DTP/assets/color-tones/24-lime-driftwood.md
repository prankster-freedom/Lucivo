# 24. 若葉ライムと流木（Lime Driftwood）

- **ID**: `lime-driftwood`
- **トーン区分**: うすい＋にぶい（pale + dull）
- **配色技法**: 色相配色（淡いライムと、灰みのティール・流木の茶を対比させる）
- **基にした配色**: `#EFEEA3`（ライム）、`#809B9A`（ティールグレー）、`#B29572`（流木の茶）
- **印象・用途**: 新芽と水辺の流木。爽やかで素朴な、アウトドア・サステナビリティの話題向け。
