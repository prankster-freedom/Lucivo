# 59. オーキッドと杏（Orchid Apricot）

- **ID**: `orchid-apricot`
- **トーン区分**: うすい＋やわらかい（pale + soft）
- **配色技法**: 色相配色（紫みのオーキッドと、黄みの杏を対比させる）
- **基にした配色**: `#CE88BA`（オーキッド）、`#FAC395`（アプリコット）、`#F8DDDE`（ピンク）
- **印象・用途**: 南国の花と果実。華やかで温かな、美容・ギフト向け。
