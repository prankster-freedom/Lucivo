# 48. パンパスグラスの輝き（Pampas Glow）

- **ID**: `pampas-glow`
- **トーン区分**: うすい＋あかるいはいみ（pale + light grayish）
- **配色技法**: アクセントカラー（クリームの地にサーモン、モーブとピンクを少し）
- **基にした配色**: `#B6A2B5`（モーブ）、`#ECA2C1`（ピンク）、`#F8C1B8`（サーモン）、`#FEECD9`（クリーム）
- **印象・用途**: 逆光のパンパスグラス。ロマンチックで穏やかな、ウェディング・ライフスタイル向け。
