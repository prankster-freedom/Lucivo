# 79. アンティークの化粧台（Antique Vanity）

- **ID**: `antique-vanity`
- **トーン区分**: うすい＋くらい（pale + dark）
- **配色技法**: アクセントカラー（淡い灰紫とピンクの地に、暗いプラムを差す）
- **基にした配色**: `#522B3D`（プラム）、`#C2BDCD`（ラベンダーグレー）、`#FAD3DA`（ピンク）
- **印象・用途**: アンティークの化粧台。優雅でクラシックな、ファッション・ジュエリー向け。
