# 30. 夕凪の港と砂（Harbor Twilight）

- **ID**: `harbor-twilight`
- **トーン区分**: うすい＋くらいはいみ（pale + dark grayish）
- **配色技法**: アクセントカラー（淡い水色とラベンダーのクールシェードに、砂色を少し差す）
- **基にした配色**: `#DAEBF3`（水色）、`#C5CCE9`（ラベンダー）、`#E7D4AD`（砂）、`#626773`（灰青）
- **印象・用途**: 凪いだ夕方の港。静かで誠実な、報告・振り返りの資料向け。
