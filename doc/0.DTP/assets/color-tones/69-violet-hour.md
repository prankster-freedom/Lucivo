# 69. 紫の刻（Violet Hour）

- **ID**: `violet-hour`
- **トーン区分**: やわらかい＋くらい（soft + dark）
- **配色技法**: セパレーション（紫を主役に、黒で引き締め、クリームで光を足す）
- **基にした配色**: `#957FAC`（パープル）、`#261C1D`（黒）、`#D8C7D2`（モーブ）、`#F9E9D1`（クリーム）
- **印象・用途**: 日没後の紫の空。幻想的で大人びた、ナイトイベント・音楽向け。
