# 13. シーグラスの浜辺（Sea Glass Shore）

- **ID**: `sea-glass-shore`
- **トーン区分**: あさい〜やわらかい（light / soft）
- **配色技法**: グラデーション（青〜青緑〜黄緑の連続色相）
- **印象・用途**: すりガラスと水の透明感が溶け合う爽快さ。UX 設計・データフロー・クラウド構成図向け。
