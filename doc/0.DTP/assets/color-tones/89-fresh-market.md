# 89. 春のマルシェ（Fresh Market）

- **ID**: `fresh-market`
- **トーン区分**: さえた＋うすい（vivid + pale）
- **配色技法**: 色相配色（淡いアクアと桃色の地に、鮮やかな黄緑とティールを）
- **基にした配色**: `#3D828E`（ティール）、`#F8E815`（レモン）、`#F8CEC1`（桃色）、`#E0F1F2`（アクアホワイト）
- **印象・用途**: 春の朝市と花。新鮮で前向きな、新生活・キャンペーン向け。
