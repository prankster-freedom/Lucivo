# 93. レモンメレンゲ（Lemon Meringue）

- **ID**: `lemon-meringue`
- **トーン区分**: ごくうすい＋うすい（very pale + pale）
- **配色技法**: 色相配色（ラベンダーとレモンの補色を、白でつなぐ）
- **基にした配色**: `#E5E460`（ライム）、`#D4DCEF`（ラベンダー）、`#F8F09B`（レモン）、`#F7F8F6`（白）
- **印象・用途**: 焼き菓子とレモン。爽やかで甘い、スイーツ・カフェ向け。
