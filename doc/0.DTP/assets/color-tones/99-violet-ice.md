# 99. 菫と氷（Violet Ice）

- **ID**: `violet-ice`
- **トーン区分**: こい＋ごくうすい（deep + very pale）
- **配色技法**: アクセントカラー（淡い氷色の地に、深い菫色を差す）
- **基にした配色**: `#624F8F`（菫）、`#BEE3EE`（氷）
- **印象・用途**: 冬の朝の窓。凛として澄んだ、案内・発表向け。
