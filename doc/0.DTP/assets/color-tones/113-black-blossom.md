# 113. 黒と白い花（Black Blossom）

- **ID**: `black-blossom`
- **トーン区分**: くらい＋あかるいはいみ（dark + light grayish）
- **配色技法**: アクセントカラー（黒とスレートの地に、コーラルを少しだけ差す）
- **基にした配色**: `#F3AE93`（コーラル）、`#3A4F59`（スレート）、`#353439`（黒）、`#D5D6D9`（グレー）
- **印象・用途**: 黒い部屋に一輪の花。洗練されたモダンな、ブランド・プロダクト紹介向け。
