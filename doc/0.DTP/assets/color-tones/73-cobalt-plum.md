# 73. コバルトとプラム（Cobalt Plum）

- **ID**: `cobalt-plum`
- **トーン区分**: こい＋あかるいはいみ（deep + light grayish）
- **配色技法**: 色相配色（深い青と紫を、淡いモーブでやわらげる）
- **基にした配色**: `#1768B2`（コバルト）、`#432A55`（深紫）、`#D8C7D2`（モーブ）
- **印象・用途**: 夜の劇場。気品と深みのある、文化・式典向け。
