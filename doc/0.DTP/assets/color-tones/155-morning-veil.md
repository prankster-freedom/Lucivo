# 155. 朝のヴェール（Morning Veil）

- **ID**: `morning-veil`
- **トーン区分**: ごくうすい（very pale）
- **配色技法**: カマイユ（ライラック・青白・ピンクを、ごくわずかな差で並べる）
- **基にした配色**: `#ECE0EC`（ライラック）、`#E9EFF4`（青白）、`#FDECF0`（ピンク）
- **印象・用途**: 朝の薄いカーテン。はかなく清らかな、ウェディング・詩向け。
