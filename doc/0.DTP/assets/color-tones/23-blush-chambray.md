# 23. 頬紅とシャンブレー（Blush Chambray）

- **ID**: `blush-chambray`
- **トーン区分**: うすい＋あかるいはいみ（pale + light grayish）
- **配色技法**: カマイユ／ドミナント・トーン（淡いピンク・クリーム・ローズベージュ・ラベンダーグレーを、近いトーンでまとめる）
- **基にした配色**: `#FBD3C5`（ピンク）、`#FBEFE1`（クリーム）、`#D4B6A4`（ローズベージュ）、`#D5D6D9`（ラベンダーグレー）
- **印象・用途**: 洗いざらしのシャツと頬紅。やさしく上品な、ファッション・ライフスタイルの紹介向け。

## カラーコード一覧

1 列目に、行ごとの配色の組（背景・文字・境界・線の色コード）を、Light と Dark に分けて書く。背景・文字・境界・線は、この組で使う。Light / Dark の列の見本は、上が「背景に使った場合」（その色の背景の上に、組の文字色）、下が「文字色に使った場合」（ベース背景の上に、その色の文字。基本色の行だけ）。見本の数字は、背景と文字のコントラスト比で、4.5 未満は、その使い方では文字が読みにくい。見本の枠は「境界」、中の短い線は「線」の色。基本色は 2〜6 色で、使わない行は「未定義」にする。
