# 170. 朝のライラック（Morning Lilac）

- **ID**: `morning-lilac`
- **トーン区分**: ごくうすい＋うすい（very pale + pale）
- **配色技法**: 色相配色（淡い青とライラックに、桃色をごく淡く添える）
- **基にした配色**: `#C4DBF2`（ブルー）、`#CDB4D7`（ライラック）、`#FEF4EE`（桃色）、`#EEF8FE`（氷）
- **印象・用途**: 朝の花瓶のライラック。やさしく澄んだ、暮らし・ギフト向け。
