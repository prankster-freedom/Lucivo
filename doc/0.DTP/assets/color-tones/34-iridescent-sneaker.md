# 34. 虹色のスニーカー（Iridescent Sneaker）

- **ID**: `iridescent-sneaker`
- **トーン区分**: うすい＋さえた（pale + vivid）
- **配色技法**: アクセントカラー（淡いピンクと水色の地に、マゼンタとオレンジを差す）
- **基にした配色**: `#E72385`（マゼンタ）、`#F8AB1E`（オレンジ）、`#A6D9E2`（アクア）、`#FAD2DB`（ピンク）
- **印象・用途**: 光で色が変わる素材。遊び心と先端感のある、ファッション・新製品の紹介向け。
