# 35. 若草の野原（Spring Meadow）

- **ID**: `spring-meadow`
- **トーン区分**: うすい＋あかるい（pale + bright）
- **配色技法**: ドミナント・トーン（4 つの色相を明るいトーンでそろえる）
- **基にした配色**: `#78ACD7`（ブルー）、`#F8AB1E`（オレンジ）、`#F2C3DB`（ピンク）、`#DAE497`（若草）
- **印象・用途**: 春の野原と小さな生き物。のびやかで朗らかな、子ども・自然の話題向け。
