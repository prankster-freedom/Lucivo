# 51. はちみつビスケット（Honey Biscuit）

- **ID**: `honey-biscuit`
- **トーン区分**: うすい＋あかるいはいみ（pale + light grayish）
- **配色技法**: ドミナント・カラー（黄みの色相でそろえる）
- **基にした配色**: `#EBCCA2`（ビスケット）、`#FFECBC`（はちみつ）
- **印象・用途**: 焼きたてのビスケット。素朴で温かな、食・カフェの話題向け。
