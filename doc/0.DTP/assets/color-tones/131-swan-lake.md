# 131. 白鳥の湖（Swan Lake）

- **ID**: `swan-lake`
- **トーン区分**: うすい＋こい（pale + deep）
- **配色技法**: 色相配色（ティールと淡いピンクの補色を、紺で引き締める）
- **基にした配色**: `#4D8F8D`（ティール）、`#F9CAC4`（ピンク）、`#354458`（紺）、`#FDEADF`（白）
- **印象・用途**: 湖を泳ぐ白鳥。優雅で物語性のある、文化・式典向け。
