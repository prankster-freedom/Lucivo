# 109. 蘭とマゼンタ（Orchid Magenta）

- **ID**: `orchid-magenta`
- **トーン区分**: さえた＋うすい（vivid + pale）
- **配色技法**: ドミナント・カラー（赤紫の色相でそろえる）
- **基にした配色**: `#C4047F`（マゼンタ）、`#CE88BA`（オーキッド）、`#F9CAC4`（ピンク）
- **印象・用途**: 温室の蘭。艶やかで華やかな、美容・ショー向け。
