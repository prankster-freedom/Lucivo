# 134. ネイビーと頬紅（Navy Blush）

- **ID**: `navy-blush`
- **トーン区分**: あかるいはいみ＋くらい（light grayish + dark）
- **配色技法**: アクセントカラー（灰みのティールと紺に、淡いピンクを添える）
- **基にした配色**: `#162A41`（紺）、`#ABC2C4`（グレーティール）、`#FCDFE7`（ピンク）
- **印象・用途**: 上品な制服。端正でやさしい、教育・案内向け。
