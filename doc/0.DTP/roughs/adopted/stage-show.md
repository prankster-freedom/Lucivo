# 採用ラフ: Visualモードの舞台演出（stage-show）

## RGH-010 シグナル・ライト（図の構造に沿って伝わる光）

```text
  背面の層: 光輪・ノードの逆光        前面の層: 白熱の芯・頭

  ╭──────╮                          時刻 0.2s  (A) が点灯
  │  A   │ ░░                       時刻 0.5s  A→B を光が進む
  ╰──┬───╯                          時刻 0.9s  (B) に届く → 逆光で輪郭が浮かぶ
     ┆ ·:=≡●   ← 尾は細く薄く、頭は白熱   時刻 0.9s  分岐は同時に分かれる
  ╭──▼───╮
  │  B   │
  ╰──────╯
```

- 主役: 図の意味（どこから、どこへ）。光を線の飾りから、意味を運ぶ信号へ変える。
- 視線誘導: 聴衆の視線が図の根から下流へ自然に運ばれる。発表者が図の順に説明する流れと揃う。
- `RGH-009` の置き換え。

## RGH-011 手順の彗星と到達の反応

```text
   (1)────────·:=≡●(2)────────────(3)────────────(4)
                    ↑ 丸の下をくぐる。届いた瞬間に丸の輪が光って広がる
```

- 図と同じ光の言語を、手順にも使う。誌面全体で光の見え方を統一する。

## RGH-012 ステージ発表（1 章 1 シーンの全画面）

```text
┌───────────────────────────────────────────────┐
│                  （上からの照明）               │
│                                               │
│  [STAGE 03] 章の見出し                         │
│                                               │
│  ┌ 01 ────┐  ┌ 02 ────┐  ┌ 03 ─ ─ ┐            │
│  │  見せた │  │ 話し中 │  ┆ まだ   ┆ ← 1 項目ずつ │
│  └────────┘  └━━━━━━━━┘  └ ─ ─ ─ ─┘            │
│                                               │
│ 章の題                         05 / 15 [操作]  │
│━━━━━━━━━━━━━━━━━━●─────────────────────────────│ ← 進行の光の線
└───────────────────────────────────────────────┘
```

- 主役: 章の中身。枠を外して舞台に直接置き、「ビューアーの画面」ではなく「発表の舞台」に見せる。
- 暗転の舞台は、シグナル・ライトが本物の光として最も映える場所でもある。
- `RGH-105`（自動進行）は、この表示の `A` キーとして統合した。

## RGH-015 俯瞰（ライトテーブル）

```text
 [O]   全画面のシーン ──縮む──▶ 升目          [Enter] 升目 ──広がる──▶ 全画面
 ┌──┐┌──┐┌──┐┌──┐
 │01││02││03││04│     実物のシーンをそのまま縮小（複製しない）
 └──┘└──┘└──┘└──┘
 ┌──┐┏━━┓┌──┐┌──┐     ┏━┓ 選択中はペールシアンの輪
 │05│┃06┃│07││08│
 └──┘┗━━┛└──┘└──┘
```

- 主役: 文書全体の構成と、いまの位置。スライドツールの「ライトテーブル」を、Markdown の章からそのまま作る。

## RGH-016 光のポインター

```text
      ░░░░░░░░░░░░░░░░░░░
    ░░░░            ░░░░    ░ = 沈めた舞台（光の外も読める濃さ）
   ░░░      ●         ░░░   ● = ルミナスホワイトの粒＋ペールシアンの光彩
    ░░░░            ░░░░
      ░░░░░░░░░░░░░░░░░░░
```

- 主役: 発表者がいま指している場所。レーザーポインターの赤い点ではなく、舞台照明のスポットライトとして見せる。

## RGH-142 ミュージアム・ウォーク（連続回廊・門の通り抜け・断面変化）

```text
  入口      門（章見出し）     通路          広間（幅・天井 2 倍強）     小部屋（狭く低い）
 ┌────┐     ┌────┐         ┌────────┐      ┌───────────────────┐       ┌─────────┐
 │題名│ ──▶ │ 01 │ ──通り抜け─▶ │壁パーツ│ ──▶ │  中央に図（層通過）  │ ──▶  │ 引用など │
 └────┘     └────┘         └────────┘      └───────────────────┘       └─────────┘
                            ↑ 立ち止まると壁のパーツへ視線が向く
```

- **主役**: 歩行そのものによる文書の連続体験（「次へ」や額単位を廃し、スクロール・`↑` `↓`・スワイプで歩くことが読み進むことになる）。
- **パーツの配置**: 小見出し・本文・箇条書き・図のパーツごとに壁からの奥行きと現れる距離をずらす。
- **区画の断面変化**: 通路一辺倒を避け、大きな図の前では広い「広間」、引用の前では狭い「小部屋」へ断面を切り替える。
- **門と図の通り抜け**: 章の見出しを門とし、広間の図も層ごとに進む向きへ並べて、近づくと画面いっぱいに広がって通り抜ける。
