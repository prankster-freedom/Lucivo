# ストックのラフ: シリーズ展開（Lucimo 系統）

状態・採否の理由・再利用の条件は [ラフ案台帳](../README.md) を正とする。

Lucimo は、[ブランドコンセプト 1.2.6](../../../1.SRS.md#126-将来のシリーズ展開における位置づけ) に定める将来のストック名称である。Lucivo（躍動・ライブステージ）と対になる、静謐・普遍・アカデミックな長文ドキュメント向けの系統とする。本書のラフは Lucivo には採り入れず、別系統の製品を始めるときの出発点として保管する。

## RGH-117 Lucimo 系統の長文組版（セリフ体、広い余白）

```text
┌──────────────────────────────────────────────────┐
│          │                              │        │
│  目次     │  第 2 章                      │ 注     │
│  1 序論   │  設計の原則      ← セリフ体・細め │ ¹ 出典 │
│ ▸2 原則   │  ── ◇ ──        ← AST-112     │ ² 補足 │
│  3 実装   │  本文は 1 行 34〜38 字。行送り  │        │
│          │  1.9。段落の頭を 1 字下げる。¹  │        │
│ 左の柱    │  ← 本文の版面は画面の 50%        │ 傍注   │
└──────────────────────────────────────────────────┘
```

- 狙い: 長文の仕様書・ナレッジを、書籍のように静かに読ませる。Lucivo の光・動き・4 色を使わず、罫と余白と文字だけで品位を出す。
- 主な違い（Lucivo との対比）:

  | 観点 | Lucivo                   | Lucimo（本案）                   |
  | :--- | :----------------------- | :------------------------------- |
  | 主役 | 1 章 1 主役のスラブ      | 連続する本文                     |
  | 書体 | サンセリフ＋丸い等幅     | セリフ体（和文は明朝）＋細い等幅 |
  | 色   | 4 色のアクセント・発光色 | 墨 1 色＋差し色 1 色             |
  | 動き | 操作に応じた光の演出     | なし（ページ送りの遷移だけ）     |
  | 装飾 | ベクター素材の光彩       | 罫とフルーロン（`AST-112`）だけ  |

- 素材の候補: `AST-112`（モノライン罫・フルーロン）を章の区切りに使う。
- ストックの理由: Lucivo の主戦場（発表・展示）と違う別系統の製品の案のため。Lucivo の Visualモードに「長文を読む」スタイルを足す要望が出ても、本案をそのまま入れず、Lucivo のトーン＆マナー（`DTP-001`）と衝突しないかを先に検討する。
