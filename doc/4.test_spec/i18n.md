## テストケース一覧

| TC ID       | 対応要求 / 設計           | テスト観点                                           | 期待結果 |
| :---------- | :------------------------ | :--------------------------------------------------- | :------- |
| TC-I18N-001 | `FR-065`, `ARC-I18N-001`  | ブラウザ言語（`en-US`）による初回自動判定、ヘッダー言語メニューからの手動切替と `localStorage` 保存 | 初回英語起動、手動で日本語/英語を切り替えられ、`lucivo-lang` に永続化される |
| TC-I18N-002 | `FR-066`, `ARC-I18N-002`〜`003` | 英語表示時の日本語残存自動検査（起動画面・メニュー・モーダル・Visual モード・ステージ発表・ミュージアム・ウォーク） | 例外（言語切替の「日本語」）を除き、画面テキストおよび属性に日本語が 0 件であること |
| TC-I18N-003 | `FR-007`, `FR-067`, `ARC-I18N-004`, `ARC-PUB-008` | 起動画面のサムネイルカード（日英画像）および言語切替時の日英サンプル自動切り替え | 起動画面カード 3 枚に英語版サムネイル（`.en.webp`）が表示されてサンプルが開き、言語切替で未編集サンプルが日英自動切替される |
| TC-I18N-004 | `DTP-004`, `ARC-I18N-005` | Visual モード英語表示の組版（字間・横はみ出しなし・校正ゲラ出力） | `html[lang="en"]` で欧文向け字間が適用され、横はみ出しがなくゲラが取得できる |
| TC-I18N-005 | `FR-065`, `ARC-PUB-009`   | Web 版のルート（`/`）からの転送。ブラウザの言語（`ja-JP`・`en-US`・`fr-FR`）、保存値（`lucivo-lang`）、`?lang=`、`#lang=`、JavaScript なし | `ja-JP` は `/ja/`、`en-US`・`fr-FR` は `/en/`、保存値はブラウザの言語より優先、`?lang=`・`#lang=` は保存値より優先する。`lang` 以外のクエリと `#` 以降はそのまま引き継ぎ、`lang` は消える。JavaScript なしは `/en/` |
| TC-I18N-006 | `FR-065`, `ARC-I18N-001`, `ARC-PUB-009` | 言語別のページの `?lang=` と、ディレクトリの優先 | `/ja/?lang=en` は `/en/` へ転送（クエリと `#` を保つ）、`/en/?lang=en` と `/ja/?lang=xx` は `lang` を消すだけで留まる。保存値が `en` でも `/ja/` は日本語で表示し、保存値は書き換えない |
| TC-I18N-007 | `FR-065`, `ARC-PUB-009`   | 言語別のページ（公開用 URL の設定）の静的な `<head>` | `<html lang>`・`data-page-lang` がページの言語、`canonical` が自分自身、`hreflang` が `en`・`ja`・`x-default`（`/en/`）、`noindex` なし、タイトルは従来のまま |
| TC-I18N-008 | `FR-065`, `FR-024`, `FR-049`, `ARC-PUB-009` | 言語の切り替えによるアドレスバーの移動（ヘッダーのメニューと「その他」メニューの項目）と、切り替えの項目の文言 | 「その他」の切り替えの項目は、切り替え先の言語で書く（日本語表示で `Switch to English`、英語表示で `日本語に切り替え`）。読み込み直さずに `/ja/` ⇔ `/en/` へ書き換わり、`#` を保ち、`lang=` を付けない。編集中の内容が残り、`<html lang>`・`data-page-lang`・`canonical`・保存値・README への導線（`/preview/en/` と `README.en.md`）が切り替え後の言語になる。起動画面のカードのリンクに `lang=` を付けない |
| TC-I18N-009 | `FR-065`, `ARC-PUB-009`（相対パス） | `/ja/`・`/en/`（1 階層深いページ）でのアセットの読み込みと既存の動き。起動画面のロゴ・サムネイル、公開 URL の文書と相対パスの画像、図・数式・整形・絵文字・光の演出・見出しの書体・ファビコン・発表モード・印刷の表示 | すべて読み込めて動き、同じオリジンへのリクエストが 1 件も失敗しない（手元の試験のサーバーの 404 が 0 件）。実行時に組み立てる参照が `../` から始まる |

言語別のページ・転送用のページ・スタンドアロン版の HTML の中身（`../` への書き換え、テスト用 URL の `noindex` と `hreflang` なし、転送用のページが 1KB 未満で CSS・画像・フォント・計測を含まないこと、スタンドアロン版が計測を含まないこと）は、単体テスト [tests/build-html-pages.test.cjs](../../tests/build-html-pages.test.cjs) で確かめる。言語の切り替えでアドレスバーを書き換える処理（`buildAppUrlWithState`）は、[tests/url-loader.test.cjs](../../tests/url-loader.test.cjs) で確かめる。どちらも `npm run lint`（`npm run test:unit`）で実行する。
