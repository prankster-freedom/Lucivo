## 共通の品質の関門（`ARC-MODE-007`）

自動テスト: [tests/e2e/present-modes.cjs](../../../tests/e2e/present-modes.cjs)。登録表のすべてのモードを検査する（モードが増減しても、TC の ID は変わらない）。文書は `notation_sample.md` を開き、発表のドロップダウンから選んで始める。`stage: "all"` のモードだけ `file://`（`dist/`）でも検査する。通らないと分かっていて直さないモードは、登録表の `gateSkip` に項目（`start`・`errors`・`narrow`・`esc`）と理由を書く（その項目は、合格として扱い、結果に理由を残す）。モードの `info().active` で、始められたか・終わったかを判定する。

| ID          | 観点                                | 手順                                                                                           | 期待結果                                                           | 確認方法 | 対応 ID        |
| :---------- | :---------------------------------- | :--------------------------------------------------------------------------------------------- | :----------------------------------------------------------------- | :------- | :------------- |
| TC-MODE-001 | 始められる（Web 版）                | Web 版で文書を開き、発表のドロップダウンから、登録されたモードを 1 つずつ選ぶ                  | どのモードも、選ぶと始まる（`info().active` が `true`）            | 自動     | `ARC-MODE-007` |
| TC-MODE-002 | コンソールのエラーがない            | TC-MODE-001 の、始める・終えるまでの間のコンソールを調べる                                     | エラーも、捕まえられなかった例外もない                             | 自動     | `ARC-MODE-007` |
| TC-MODE-003 | スマホの幅で横にはみ出さない        | 幅 390px にしてから、モードを始める                                                            | `document.documentElement.scrollWidth` が画面の幅（390）を超えない | 自動     | `ARC-MODE-007` |
| TC-MODE-004 | `Esc` で元の表示に戻る              | 高速モードで、プレビューを 300px スクロールしてから始め、`Esc` を押す                          | モードが終わる（`info().active` が `false`）。描画モード（高速 / Visual）、表示の切り替え（Split / Canvas）、スクロールの位置（±2px）が始める前と同じ | 自動 | `ARC-MODE-007` |
| TC-MODE-005 | Web 版だけのモードを、スタンドアロン版に入れない | スタンドアロン版（`dist/`）を `file://` で開き、発表のドロップダウンを開く。`dist/js/modes/`・`dist/css/modes/` を調べる | `stage: "web"` のモードの項目がメニューになく、そのモードの JS・CSS のファイルが `dist/` にない | 自動 | `ARC-MODE-002` |
| TC-MODE-006 | 展開したモードが `file://` でも通る | `stage: "all"` のモードを、`dist/` を `file://` で開いて TC-MODE-001〜004 と同じように検査する | すべて合格する（`stage: "all"` のモードがなければ、対象なし）      | 自動     | `ARC-MODE-007` |
