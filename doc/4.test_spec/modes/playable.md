# テスト仕様: プレイアブル・ダイアグラム（`playable`）

要求: [playable.md](../../1.SRS/features/modes/playable.md)（`FR-055`）／詳細設計: [playable.md](../../3.sw_design_notes/features/modes/playable.md)／自動テスト: [tests/e2e/modes/playable.cjs](../../../tests/e2e/modes/playable.cjs)／目次: [README.md](README.md)

共通の品質（始められる・コンソールのエラーがない・スマホの幅で横にはみ出さない・`Esc` で元の表示に戻る）は、目次の関門（`TC-MODE-001`〜`006`）で確かめる。この仕様は、このモードの体験の核心だけを確かめる。

テストの中の HTTP サーバーで `http://` で開いて確かめる。文書は `notation_sample.md`（フローチャート・状態遷移図を含む）を「ファイルを開く…」で開く。
