# テスト仕様: ズーミング・マップ（`zoom-map`）

要求: [zoom-map.md](../../1.SRS/features/modes/zoom-map.md)（`FR-054`）／詳細設計: [zoom-map.md](../../3.sw_design_notes/features/modes/zoom-map.md)／自動テスト: [tests/e2e/modes/zoom-map.cjs](../../../tests/e2e/modes/zoom-map.cjs)／目次: [README.md](README.md)

共通の品質（始められる・コンソールのエラーがない・スマホの幅で横にはみ出さない・`Esc` で元の表示に戻る）は、目次の関門（`TC-MODE-001`〜`006`）で確かめる。この仕様は、このモードの体験の核心だけを確かめる。

Web 版の TC は、テストの中で `public/` を配る小さな HTTP サーバー（`startWebServer()`）を立て、`http://` で開いて確かめる。文書は `visual-sample.md`（表紙と 18 章）を「ファイルを開く…」で開く。
