# テスト仕様: ミュージアム・ウォーク（`museum-walk`）

要求: [museum-walk.md](../../1.SRS/features/modes/museum-walk.md)（`FR-056`）／詳細設計: [museum-walk.md](../../3.sw_design_notes/features/modes/museum-walk.md)／自動テスト: [tests/e2e/modes/museum-walk.cjs](../../../tests/e2e/modes/museum-walk.cjs)／目次: [README.md](README.md)

共通の品質（始められる・コンソールのエラーがない・スマホの幅で横にはみ出さない・`Esc` で元の表示に戻る・スタンドアロン版に入れない）は、目次の関門（`TC-MODE-001`〜`006`）で確かめる。この仕様は、このモードの体験の核心だけを確かめる（`AGENTS.repo.md` 10 章の「Web 版だけ」の段階）。

Web 版の TC は、テストの中で `public/` を配る小さな HTTP サーバー（`startWebServer()`）を立て、`http://` で開いて確かめる。文書は `visual-sample.md`（表紙と 17 章。図 5 つ、引用とコールアウト 5 つ）を「ファイルを開く…」で開く。位置を決めて確かめるときは、モードの `walkTo(z)`（その位置へ移り、向きと立つ位置を落ち着き先まで進める）を使う。確かめた場面のスクリーンショット（`mw-*.png`）を、校正（dtp）のゲラとして残す。
