# テスト仕様: 図ごとの矢印の形状（edge-style）

`index.html` を `file://` で開き、`notation_sample.md` を読み込んでから実施する。確認方法が「自動」の TC は [tests/e2e.cjs](../../tests/e2e.cjs) で確認する。結線の形は、Mermaid が出力する結線のパス（フローチャートは `path.flowchart-link`、状態遷移図は `path.transition`、クラス図は `path.relation` の `d` 属性）に曲線の命令（`C`）があるかどうかで判定する。

| :---------- | :------------------------- | :--------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :------- | :------------------------------------ |

結線の端の区間は、`path.relation` の `d` 属性の座標を順に読み、記号の付く端の 2 点（始点側は最初の 2 点、終点側は最後の 2 点。曲線の命令では制御点と終点）から求める。TC-EDGE-007 は、直角で `stepAfter` を使っていたとき（出発点の区間が横向きで、x の差が約 13.6px）に失敗することを確認している。
