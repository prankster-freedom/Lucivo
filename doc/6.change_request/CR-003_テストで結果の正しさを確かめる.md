# CR-003 テストで結果の正しさを確かめる

| 項目     | 内容                                                                                  |
| :------- | :------------------------------------------------------------------------------------ |
| 分類     | 不具合                                                                                |
| 状態     | 登録                                                                                  |
| 優先度   | 中                                                                                    |
| 起票の元 | 0.2.0 のリリース前の点検（`CR-001` と、構文エラーの表示が積み上がる不具合の振り返り） |
| 戻る工程 | test                                                                                  |
| 対応     | 未着手（今後の改善の検討事項）。構文エラーの後片付けは `TC-DIAG-025` で対応済み       |

## 1. 要求の内容

0.2.0 のリリース前の点検で見つかった次の不具合は、どれもテストが合格していた。

- 章の画像化が誌面にならない（`CR-001`）: TC-VTPL-017 は PNG ができたかだけを確かめていた。
- HTML の書き出しが持ち出し先で崩れる（`CR-001`）: TC-OFF-003・TC-MATH-009 は書き出した HTML の文字列だけを確かめ、ファイルを開いていなかった。
- 構文エラーの図がページの下に積み上がる: 構文エラーの TC は、プレビューの表示だけを確かめ、ページのほかの場所に残るものを確かめていなかった（`TC-DIAG-025` を追加して対応済み）。

ほかの TC にも、同じく「結果ができたか」だけを確かめている箇所がないかを見直したい。

## 2. 分析

### 2.1 現在の仕様との関係

test スキルは、画面の見た目の確認で「要素があることだけでなく、利用者に見分けられることまで確かめる」と定めている。出力（画像・ファイル）や後片付けについても、同じ考え方が要る。

### 2.2 原因

出力を作る機能の TC が、出力の有無や形式（Blob の型、文字列の一部）を確かめるところで止まっていた。

## 3. 影響範囲

| 種別   | ID                                                              | 影響                                                                                             |
| :----- | :-------------------------------------------------------------- | :----------------------------------------------------------------------------------------------- |
| テスト | 出力を作る機能の TC（図の `PNG` / `SVG`、保存、印刷・PDF など） | 出力の中身（画像の見た目、ファイルを開いた表示）と、操作の後に余計なものが残らないことを確かめる |

## 4. 対応方針

- 採る案: 未定（今後の改善の検討事項）。出力を作る機能の TC を洗い出し、出力の中身まで確かめているかを見直す。test スキルに、出力と後片付けの確認の観点を加えることも検討する。
- 規模の見積もり: 中（TC の洗い出しと、必要な TC の追加）。

## 5. 対応結果

- 未着手。
