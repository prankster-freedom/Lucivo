# CR-002 無害化で style 属性を通す

| 項目     | 内容                                              |
| :------- | :------------------------------------------------ |
| 分類     | 仕様の変更                                        |
| 状態     | 登録                                              |
| 優先度   | 低                                                |
| 起票の元 | 0.2.0 のリリース前の点検（Claude のコードの点検） |
| 戻る工程 | swe1（`NFR-003` で許す属性を決める）              |
| 対応     | 未着手（今後の改善の検討事項）                    |

## 1. 要求の内容

Markdown に書いた HTML の `style` 属性が、無害化の後も残る。文書の書き方次第で、`position: fixed` などで画面の操作部（ヘッダーやボタン）を覆う表示ができる。

## 2. 分析

### 2.1 現在の仕様との関係

`NFR-003` は「Markdown から生成した HTML は DOMPurify でサニタイズしてから DOM に反映する」と定め、どの属性を許すかは定めていない。実装（`app.js` の `renderApp()`）は `ADD_ATTR: ['class', 'data-slot', 'style']` で `style` を許している。スクリプトは実行されないため、仕様の範囲内の動きだが、許す範囲を見直す余地がある。

### 2.2 原因

文書の装飾（色や揃え）のために `style` を許している。

## 3. 影響範囲

| 種別   | ID                               | 影響                                                   |
| :----- | :------------------------------- | :----------------------------------------------------- |
| 要求   | `NFR-003`                        | 許す属性、または `style` で許すプロパティを定める      |
| 設計   | `DD-MD-*`（Markdown 要素の表示） | `style` を許さない、または危険なプロパティ（`position` など）を取り除く処理を足す |
| テスト | （新規）                         | 画面の操作部を覆う `style` が効かないことを確かめる TC |

## 4. 対応方針

- 採る案: 未定（今後の改善の検討事項）。
- 判断の材料: Lucivo は手元のファイルを見るビューアーで、開く文書は利用者が選ぶため、危険は小さい。一方、配布された文書を開く使い方では、操作部を覆って誤操作を誘う表示ができる。
- 規模の見積もり: 小〜中（`style` を許す範囲によって、同梱サンプルの表示の確認が要る）。
- 注意: `<img style="width: …">` で画像の大きさを変える書き方が使われている（`FR-042`）。`style` を許さない場合は、画像の `width`・`height` 属性で代わりに指定できることを案内するか、大きさのプロパティを残す。
