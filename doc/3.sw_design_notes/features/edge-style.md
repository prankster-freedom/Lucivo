# 図ごとの矢印の形状（edge-style）

対応する要求: `FR-012`, `FR-004`（[1.SRS.md](../../1.SRS.md) および [1.SRS/features/edge-style.md](../../1.SRS/features/edge-style.md)）／アーキテクチャ: [2.ARCHITECTURE.md](../../2.ARCHITECTURE.md) 4.8

## 1. 設計

| ID          | 項目        | 設計                                                                                                                                                                                                                                          | 対応する要求 |
| :---------- | :---------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------- |
| DD-EDGE-001 | 対象の判定  | `getCurveTarget(code)` は、Mermaid のコードの先頭（空行、`%%` で始まる行を除く最初の行）が `flowchart` / `graph` で始まれば `'flowchart'`、`stateDiagram` で始まれば `'state'`、`classDiagram` で始まれば `'class'`、それ以外は `null` を返す | `FR-012`     |
| DD-EDGE-002 | 既定の形状  | `DEFAULT_CURVES = { flowchart: 'step', state: 'smooth', class: 'step' }`。対象の図種ごとの既定の形状を持つ。対象外の図種は Mermaid の描画のまま（ER 図は曲線）                                                                                | `FR-012`     |
| DD-EDGE-003 | 選択の保持  | `state.curveByIndex`（`Map`、図の番号 → `'smooth'` / `'step'` / `'straight'`）。値がない図は既定の形状を使う。ファイルを読み込んだときに空にする。表示モードの切替では変えない                                                                | `FR-012`     |
| DD-EDGE-004 | 描画への反映 | `renderApp()` は、図ごとに形状 `curve`（`getBlockCurve(index, code)`）を求め、キャッシュのキーのハッシュに含める。`processDirtyBlocks()` は、図ごとに `setupMermaid(isVisual, curve)` を呼んでから描画する。`setupMermaid` は `curve` を `basis` / `stepAfter` / `linear` に変換し、`flowchart.curve`・`state.curve`・`class.curve` に同じ値を渡す（描画する図の図種の設定だけが効く）。レイアウトは `getMermaidLayout(code, curve)` で決める（DD-EDGE-005） | `FR-012` |
| DD-EDGE-005 | 直角のクラス図のレイアウト | `getMermaidLayout(code, curve)` は、`curve === 'step'` で `getCurveTarget(code) === 'class'` のとき `null`（Mermaid 12 の既定のレイアウト）を返す。それ以外は従来どおり（マインドマップは `null`、他は `'dagre'`）。既定のレイアウトは `curve` の設定によらず、線を縦 → 横 → 縦の角の丸い直角で結ぶ | `FR-012` |
| DD-EDGE-010 | 選択の UI   | 対象の図のカードのヘッダーに、`曲線` / `直角` / `直線` の 3 つのボタン（`.edge-curve-btn`、`data-curve`、`data-index`）を置く。選択中のボタンに `is-active` と `aria-pressed="true"` を付ける。対象外の図には置かない                         | `FR-012`     |
| DD-EDGE-011 | 選択の操作  | ボタンを押すと `state.curveByIndex` を更新して `renderApp()` を呼ぶ。選んだ図だけキャッシュのキーが変わるため、その図だけが描き直される                                                                                                       | `FR-012`     |
| DD-EDGE-020 | 廃止する UI | スタイルバーと設定モーダルの「矢印形状」の切替（`.curve-option-btn`）と、`state.curve` を削除する                                                                                                                                             | `FR-004`     |

- **背景（DD-EDGE-001, 002）**: Mermaid `10.9` 系で矢印の形状の設定（`curve`）が効くのはフローチャートだけだった。状態遷移図・クラス図・ER 図は、`flowchart` / `state` / `class` / `er` のどの設定でも結線の形が変わらないことを確認した（要求仕様書 `FR-012`）。`12.3.0` では状態遷移図とクラス図でも効く（ER 図は変わらない）ため、対象に加えた。
- **背景（DD-EDGE-005）**: 直角の `stepAfter` は、2 点の間を「先に横、次に縦」で結ぶ。dagre は線の出発点を、箱の中心から次の点へ向かう直線と箱の辺の交点に置く。このため、1 つの親から子が複数出ると出発点が下辺の中央からずれ、最初の区間が横向きになって、線が親の箱の下辺に沿って走る。クラス図の継承（`<|--`）・コンポジション（`*--`）・集約（`o--`）の記号は線の出発点に付き、向きは最初の区間で決まるため、横を向いた（例: `M105.2,184.5 L91.6,184.5 L91.6,197.5 …`）。
  - **採らなかった案**: `stepBefore`（先に縦）は、到着点の区間が横向きになり、終点に付く矢じり（`-->`）が横を向く。dagre の座標を直角に引き直す案は、Mermaid が記号の分だけ線を短くした後の座標を扱うことになり、手間と壊れやすさが大きい。
  - **フローチャートと状態遷移図を dagre のままにする理由**: 同梱サンプルの全部の図を見比べると、既定のレイアウトは分岐する線に小さな S 字の折れが入り、ひし形の分岐の左右の出方も崩れた。これらの図種は記号が終点側にしか付かず、`stepAfter` の終点の区間は縦になるため、向きの崩れは起きない。
  - **注意**: 既定のレイアウトでは、`直角` と `曲線` / `直線` を切り替えると箱の並び方も少し変わる（どちらも上から下への階層の配置は同じ）。
- **背景（DD-EDGE-003）**: 選択は文書に書き込まない（要求仕様書 `FR-012`）。図の番号で保持するため、図を追加・削除すると、それより後ろの図の選択がずれることがある。画面の表示の間だけの設定のため、許容する。
