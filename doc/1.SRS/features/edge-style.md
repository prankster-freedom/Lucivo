# Feature Requirement Specification: edge-style

本ドキュメントは、Lucivo におけるテーマ（Light / Dark）・アクセントカラーパレット切替、およびダイアグラムごとの結線（矢印）形状選択に関する機能要求仕様を定義する。

対応する全体 SRS: [doc/1.SRS.md](../../1.SRS.md)

## 対象機能要求一覧

| ID     | 機能名               | 概要 |
| :----- | :------------------- | :--- |
| FR-004 | テーマ・パレット切替 | Light / Dark 外観切替、および 4 種のカラーパレット（Cobalt / Emerald / Amber / Royal）を切り替える |
| FR-012 | 図ごとの矢印の形状   | 矢印の形状（曲線 / 直角 / 直線）を図ごとに選べるようにする。既定値は図種ごとに最適な形状とする |

---

## 機能要求の詳細

### FR-004: テーマ・パレット切替

- ヘッダーの操作から Light / Dark の外観テーマを即座に切り替えられること。
- 4 種類のアクセントカラーパレット（Cobalt, Emerald, Amber, Royal）を選択・適用できること。
- Dark 外観時も Visualモードの各カード背景、文字、結線、境界線が十分に識別できるコントラスト（NFR-004）を保つこと。

### FR-012: 図ごとの矢印の形状

- **対象図種**: フローチャート（flowchart）・状態遷移図（stateDiagram）・クラス図（classDiagram）を対象とし、各ダイアグラムカードのヘッダー内で形状（曲線 / 直角 / 直線）を個別に選択できること。
- **図種ごとの既定の形状**:

  | 図種           | 既定の形状           | 選定理由                                                           |
  | :------------- | :------------------- | :----------------------------------------------------------------- |
  | フローチャート | 直角（Step）         | 業務フロー図・処理フロー図では直角の結線が最も標準的で視認性が高い |
  | 状態遷移図     | 曲線（Smooth）       | UML ステートマシン図では曲線が一般的（Mermaid の既定値と一致）     |
  | クラス図       | 直角（Step）         | クラス間の関係は直角の結線が一般的で、継承の階層が読み取りやすい   |
  | ER 図          | 曲線（Mermaid 固定） | Mermaid（`12.3.0`）が形状の変更に対応していないため、選択の対象外  |

  状態遷移図とクラス図は、Mermaid `12.3.0` で形状を変えられるようになったため対象に加えた。

- **直角の結線の品質**: 直角では、線を箱に対して垂直に出入りさせる。線の端に付く記号（クラス図の継承の三角形、集約・コンポジションのひし形、矢じり）は、線の流れの向き（上から下へ流れる図では上下）を向くこと。箱の辺に沿って線を走らせない。
  - **背景・根拠**: 1 つの親から子が複数出るクラス図で、線の出発点の区間が横向きになり、継承の三角形が横を向いて、継承の向きが読み取りにくかった。

- **状態の保持**: 選択した形状はセッション（現在の画面表示）の間維持され、ファイルを再読み込みした場合は図種ごとの既定値にリセットされる。元の Markdown ファイルへの書き込みは行わない。
- **背景・根拠**: 全体で一律に結線形状を強制すると、フローチャートには適しても他の図種に不自然な結線となるため、図ごとの選択を可能とした。文書全体への一括切替機能（スタイルバー等）は廃止した。
