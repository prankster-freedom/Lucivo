# Feature Requirement Specification: i18n

本ドキュメントは、Lucivo における多言語表示（当面は日本語・英語の 2 言語）に関する機能要求仕様を定義する。

対応する全体 SRS: [doc/1.SRS.md](../../1.SRS.md)

## 対象機能要求一覧

| ID     | 機能名                             | 概要 |
| :----- | :--------------------------------- | :--- |
| FR-065 | 表示言語の判定・切り替え・保存     | ブラウザ言語による初回判定、ヘッダーからの手動切り替え、`localStorage` と URL パラメータへの反映 |
| FR-066 | 英語表示の対象範囲と例外定義       | 画面 UI・描画時挿入文字・発表モード・ドキュメントの英語化と、英語表示で残してよい例外の定義 |
| FR-067 | 同梱サンプルの言語別提供と切り替え | 日本語版・英語版の同梱サンプルを別ファイルで持ち、表示言語に合わせて開く |

---

## 機能要求の詳細

### FR-065: 表示言語の判定・切り替え・保存

- 対応言語は、当面は日本語（`ja`）と英語（`en`）の 2 言語とする。
- 起動時の表示言語は次の優先順位で決める。
  1. URL パラメータ（`?lang=ja|en` または `#lang=ja|en`）
  2. `localStorage`（キー `lucivo-lang`）に保存された値
  3. ブラウザの言語設定（`navigator.language` が `ja` で始まる場合は `ja`、それ以外は `en`）
- ヘッダーに言語切り替え UI を配置し、利用者がいつでも `日本語` / `English` を切り替えられるようにする。
- 言語を切り替えたときは、`localStorage` に保存し、`<html lang>` 属性・画面上のすべての UI 文言・プレビュー内の自動生成文言・ウィンドウタイトルを即時更新する。
- **背景・根拠**: 日本語を読めない利用者が初回アクセス時から迷わず使えるようにするため、ブラウザの言語設定で自動判定しつつ、手動切り替えと再訪時の保持を両立する。

### FR-066: 英語表示の対象範囲と例外定義

- 一般ユーザーに触れるすべての日本語を英語でも表示できるようにする。対象は次のとおり。
  - 画面のメニュー、ボタン、ツールチップ、`aria-label`、プレースホルダ、モーダル、トースト、エラー表示
  - 描画のときに自動挿入される文字（コールアウト見出し、脚注見出し、目次、表紙スペックバッジ・ボタン、コードコピーボタンなど）
  - ステージ発表および発表モード（ミュージアム・ウォーク等）
  - 一般ユーザー向けドキュメント（`README.en.md`、`SECURITY.md`、`release-notes.en.md`）
  - ※ロゴ素材（`AST-010`〜`012`）には日本語が含まれないため対象外とする。
- Visual モードの英語表示においても、`AGENTS.repo.md` 5 章の品質基準（トップデザイナーが制作したと思える品質）を満たすこと（`DTP-004`）。
- 英語表示（`lang="en"`）においては、以下の **3 つの例外** を除き、画面上に日本語文字（ひらがな・カタカナ・漢字・全角約物等）が出ないこと。この制約は E2E 自動テストで継続的に検証する。
  1. 言語の切り替え UI で自分の言語名として表す「`日本語`」
  2. 利用者が開いた文書の中身（プレビュー内のユーザー文書・エディタ内のユーザー入力）
  3. 内部の CSS 等に含まれるフォント名
- **背景・根拠**: 初版で英語表示に日本語が一部でも残ると、海外の利用者への品質印象を損ねるため、例外を厳密に定義して自動テストで漏れを防ぐ。

### FR-067: 同梱サンプルの言語別提供と切り替え

- 同梱サンプルは、日本語版（`<name>.md`）と英語版（`<name>.en.md`）を別のファイルとして `public/samples/` に用意する。
- 「開く」メニューおよび起動画面（`FR-007`）の同梱サンプルリンクから開くときは、現在の表示言語に合わせて日本語版・英語版のファイルを開き、ウィンドウタイトル（`FR-040`）も開いたファイル名にする。Web 版では、GitHub 上の同名のファイルを読み込む（`FR-068`）。英語版がないサンプルは、日本語版を開く。
- 言語を切り替えた時点で同梱サンプルを開いており、かつエディタが未編集状態の場合は、切り替え後の言語のサンプルを自動で読み込み直す（編集中の場合は変更を失わないよう現在の文書を保つ）。
- **背景・根拠**: 日本語の組版（`word-break: auto-phrase` 等）を見せるサンプルを英語に置き換えると検証・訴求したい内容が変わってしまうため、日英両方のファイルを独立して保持する。
