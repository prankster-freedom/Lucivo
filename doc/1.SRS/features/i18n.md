# Feature Requirement Specification: i18n

本ドキュメントは、Lucivo における多言語表示（当面は日本語・英語の 2 言語）に関する機能要求仕様を定義する。

対応する全体 SRS: [doc/1.SRS.md](../../1.SRS.md)

## 対象機能要求一覧

| ID     | 機能名                             | 概要 |
| :----- | :--------------------------------- | :--- |
| FR-065 | 表示言語の判定・切り替え・保存     | ブラウザ言語による初回判定、ヘッダーからの手動切り替え、`localStorage` と URL への反映、Web 版の言語別のページ（`/ja/`・`/en/`）とルートからの転送 |
| FR-066 | 英語表示の対象範囲と例外定義       | 画面 UI・描画時挿入文字・発表モード・ドキュメントの英語化と、英語表示で残してよい例外の定義 |
| FR-067 | 同梱サンプルの言語別提供と切り替え | 日本語版・英語版の同梱サンプルを別ファイルで持ち、表示言語に合わせて開く |

---

## 機能要求の詳細

### FR-065: 表示言語の判定・切り替え・保存

- 対応言語は、当面は日本語（`ja`）と英語（`en`）の 2 言語とする。
- 起動時の表示言語は次の優先順位で決める。
  1. ページの言語のディレクトリ（Web 版の `/ja/`・`/en/`）、または URL パラメータ（`?lang=ja|en` または `#lang=ja|en`）
  2. `localStorage`（キー `lucivo-lang`）に保存された値
  3. ブラウザの言語設定（`navigator.language` が `ja` で始まる場合は `ja`、それ以外は `en`）
- ヘッダーに言語切り替え UI を配置し、利用者がいつでも `日本語` / `English` を切り替えられるようにする。
- 言語切り替え UI の項目は、切り替え先の言語で書く。言語を選ぶ項目は、その言語の名前（`日本語`・`English`）とし、もう一方の言語へ切り替える項目（「その他」メニュー）は、日本語表示では `Switch to English`、英語表示では `日本語に切り替え` とする。ヘッダーの言語切り替えボタンのツールチップと読み上げ（`aria-label`）は、今の言語に、切り替え先の言語を添える（日本語表示では `表示言語を切り替え / Change language`、英語表示では `Change language / 表示言語を切り替え`）。
  - 背景・根拠: 言語を切り替えたい人は、今表示されている言語を読めない。今の言語で「English に切替」と書くと、英語に切り替えたい人（日本語を読めない人）が、項目を見つけられない。
- 言語を切り替えたときは、`localStorage` に保存し、`<html lang>` 属性・画面上のすべての UI 文言・プレビュー内の自動生成文言・ウィンドウタイトルを即時更新する。
- **Web 版の言語別のページ**: Web 版（公開用 URL とテスト用 URL `/preview/`）は、言語ごとのページを、別のディレクトリに置く（#443）。
  - 日本語版は `/ja/`、英語版は `/en/` とする。各ページの HTML には、その言語の `<html lang>` と、自分自身を指す `canonical` を、静的に書く。公開用 URL のページには、`hreflang`（`en`・`ja`・`x-default`。`x-default` は `/en/`）も書く。テスト用 URL のページには、検索に出さない指定（`<meta name="robots" content="noindex">`）を書き、`hreflang` は書かない。
  - ルート（`/`、`/preview/`）は、言語別のページへ転送するだけのページとする。転送先は、上の優先順位の 1 の URL パラメータ・2・3 で決めた言語のディレクトリとする。JavaScript が動かない環境では、`/en/` へ転送する。転送用のページには、CSS・画像・Web フォント・利用状況の計測（`FR-063`）を含めず、1KB 未満にする。転送は履歴を残さない。
  - `?lang=`・`#lang=` つきの URL は、正規の URL として使わない。ルートと言語別のページのどちらで開いても、その言語のディレクトリへ転送する。この転送は恒久的に残す。やめるときは本要求の変更として扱う。
  - 転送するときは、`lang` 以外のクエリ（`url`・`mode`・`view`・`layout`・`present` など）と、`#` 以降をそのまま引き継ぐ。
  - 言語別のページを開いたときは、ディレクトリの言語で表示する。`localStorage` の保存値やブラウザの言語より優先し、保存値は書き換えない。
  - 言語を切り替えたときは、ページを読み込み直さずに、アドレスバーを、もう一方の言語のディレクトリへ書き換える（履歴を増やさない。クエリと `#` 以降は引き継ぐ）。アドレスバーの URL と、画面の言語を、常に一致させる。
  - 共有する URL（アドレスバーの URL、起動画面のサンプルのカードのリンク、README への導線）は、`?lang=` を付けず、言語のディレクトリで言語を表す。
  - スタンドアロン版（`file://` で開く `index.html`）は、言語別のページを持たず、1 つの `index.html` のまま、上の優先順位（URL パラメータ・保存値・ブラウザの言語）で言語を決める。言語を切り替えたときは、従来どおり、英語のときだけアドレスバーに `lang=en` を書く。
- **背景・根拠**: 日本語を読めない利用者が初回アクセス時から迷わず使えるようにするため、ブラウザの言語設定で自動判定しつつ、手動切り替えと再訪時の保持を両立する。
- **背景・根拠（言語別のページ）**: 1 つの HTML を JavaScript で切り替える方式では、検索エンジンが取り込む HTML が言語で変わらず、検索結果に、英語のタイトルと日本語の説明文が混ざって出ていた。言語ごとに別の URL と HTML を用意し、`hreflang` で対応を示すことで、検索結果の言語を、ページの言語にそろえる（効果は検索エンジンの取り込み次第で、保証はできない）。
  - 言語の切り替えでページを読み込み直さないのは、読み込み直すと、編集中の内容や、開いているローカルのファイル・フォルダが失われるためである。言語別のページは、どちらも同じ深さのディレクトリにあり、アセットを共有しているため、アドレスバーだけを書き換えても、相対パスの参照は変わらない。
  - 採らなかった案: `?lang=en` のまま `hreflang` だけ書く案（HTML が言語で変わらず、検索エンジンが区別できない）、ルートを常に `/en/` へ転送する案（日本語のブラウザで `/` を開いた人が英語になり、ブラウザの言語による判定と食い違う）、言語の切り替えで、もう一方のページを読み込み直す案（編集中の内容が失われる）。

### FR-066: 英語表示の対象範囲と例外定義

- 一般ユーザーに触れるすべての日本語を英語でも表示できるようにする。対象は次のとおり。
  - 画面のメニュー、ボタン、ツールチップ、`aria-label`、プレースホルダ、モーダル、トースト、エラー表示
  - 描画のときに自動挿入される文字（コールアウト見出し、脚注見出し、目次、表紙スペックバッジ・ボタン、コードコピーボタンなど）
  - ステージ発表および発表モード（ミュージアム・ウォーク等）
  - 一般ユーザー向けドキュメント（`README.en.md`、`SECURITY.md`、`release-notes.en.md`）
  - ※ロゴ素材（`AST-010`〜`012`）には日本語が含まれないため対象外とする。
- Visual モードの英語表示においても、`AGENTS.repo.md` 5 章の品質基準（トップデザイナーが制作したと思える品質）を満たすこと（`DTP-004`）。
- 英語表示（`lang="en"`）においては、以下の **3 つの例外** を除き、画面上に日本語文字（ひらがな・カタカナ・漢字・全角約物等）が出ないこと。この制約は E2E 自動テストで継続的に検証する。
  1. 言語の切り替え UI で、切り替え先の言語で書く文言（言語名の「`日本語`」、「`日本語に切り替え`」、言語切り替えボタンのツールチップと読み上げに添える「`表示言語を切り替え`」。`FR-065`）
  2. 利用者が開いた文書の中身（プレビュー内のユーザー文書・エディタ内のユーザー入力）
  3. 内部の CSS 等に含まれるフォント名
- **背景・根拠**: 初版で英語表示に日本語が一部でも残ると、海外の利用者への品質印象を損ねるため、例外を厳密に定義して自動テストで漏れを防ぐ。

### FR-067: 同梱サンプルの言語別提供と切り替え

- 同梱サンプルは、日本語版（`<name>.md`）と英語版（`<name>.en.md`）を別のファイルとして `public/samples/` に用意する。
- 「開く」メニューおよび起動画面（`FR-007`）の同梱サンプルリンクから開くときは、現在の表示言語に合わせて日本語版・英語版のファイルを開き、ウィンドウタイトル（`FR-040`）も開いたファイル名にする。Web 版では、GitHub 上の同名のファイルを読み込む（`FR-068`）。英語版がないサンプルは、日本語版を開く。
- 言語を切り替えた時点で同梱サンプルを開いており、かつエディタが未編集状態の場合は、切り替え後の言語のサンプルを自動で読み込み直す（編集中の場合は変更を失わないよう現在の文書を保つ）。
- **背景・根拠**: 日本語の組版（`word-break: auto-phrase` 等）を見せるサンプルを英語に置き換えると検証・訴求したい内容が変わってしまうため、日英両方のファイルを独立して保持する。
