# Feature Requirement Specification: file-loading

本ドキュメントは、Lucivo におけるファイル操作およびエディタの保護・初期状態に関する機能要求仕様を定義する。

対応する全体 SRS: [doc/1.SRS.md](../../1.SRS.md)

## 対象機能要求一覧

| ID     | 機能名                      | 概要                                                                     |
| :----- | :-------------------------- | :----------------------------------------------------------------------- |
| FR-006 | Markdown ファイルの読み込み | ヘッダーの「ファイル」メニューからローカルファイルをエディタに読み込み、プレビューを更新する |
| FR-007 | 起動時の初期表示            | 起動直後のエディタは空とし、プレビューに案内を表示する                   |
| FR-013 | Markdown の保存             | 「保存」ボタンでエディタの内容を Markdown ファイルとしてダウンロードする |
| FR-014 | 読み込み直後の読み取り専用  | ファイル読み込み直後はエディタを読み取り専用とし、「閲覧」「編集」の切り替えで切り替える |

---

## 機能要求の詳細

### FR-006: Markdown ファイルの読み込み

- ヘッダーの「ファイル」メニューの「Markdown を開く…」から、ローカルの `.md` / `.markdown` / `.txt` ファイルをエディタに読み込み、プレビューを即座に更新する。
- 同メニューの下段に同梱サンプル項目として上段に「`Visualモードサンプル (visual-sample.md)`」、中段に「`記法サンプル (notation_sample.md)`」、下段に「`記法サンプル追補版 (notation_sample_extra1.md)`」を配置し、ファイル選択ダイアログを経由せずワンクリックで読み込めるようにする。
- エディタの内容を、最後に読み込んだ時点から編集していた場合（起動直後の空の状態から入力した場合を含む）は、置き換える前に確認ダイアログを表示し、ユーザーが誤って未保存の変更を破棄しないよう取り消せるようにする。
- ブラウザ標準のファイル選択（`<input type="file">`）および同梱サンプルの遅延スクリプトフォールバック（`samples/samples-data.js`）により、`index.html` をローカル環境で `file://` で直接開いた場合でも動作を保証する。

### FR-007: 起動時の初期表示

- 起動直後のエディタは空の状態とする。
- プレビュー領域には、上部に公式ブランド・フルバナーロゴ（`AST-012`、`DTP-005`。外観の Light / Dark に連動）を掲出し、本プロダクトの差別化ポイント（思考を妨げない「高速モード」、講演・展示素材品質の「Visualモード」、全画面の臨場感ある「ステージ発表」）と、画面上部のセグメントボタンや発表ボタンでいつでも切り替えられること、`?` キーでキーボードショートカット一覧を表示できることの簡潔な説明、および「ファイル」メニューから Markdown を開く案内を表示する。
- サンプル文書は `app.js` 内にハードコードして埋め込まず、同梱の `notation_sample.md` として配布し、ユーザーが必要に応じて FR-006 で開く形態とする。
- **背景・根拠**: ソースコード内にサンプル文書を埋め込むとコードの保守性が低下する。また起動時に `notation_sample.md` を fetch 等で自動読み込みする方式は、`file://` プロトコルで開いた場合にブラウザの CORS/ローカルファイルアクセス制約でエラーとなり、開き方によって挙動が変わるため採用しない。また、初期画面で Visualモードの存在を明示することで、ユーザーが展示品質の魅力に触れずに離脱することを防ぐ。

### FR-024: 公開リポジトリへの導線

- メインヘッダー左端のロゴと、起動時の案内（FR-007）のロゴを、公開リポジトリ（https://github.com/prankster-freedom/Lucivo）へのリンクにする。
- 起動時の案内の最後に「最新版はこちら」の一文と、同じ公開リポジトリへのリンクを表示する。
- リンクは新しいタブで開き、開いたページから Lucivo の画面を操作できないようにする（`rel="noopener noreferrer"`）。
- **背景・根拠**: Lucivo はダウンロードしてローカルで開く配布形態のため、利用者が手元の版が最新かを確かめる手段がない。配布元への導線を、常に見えるロゴと起動時の案内に置く。インターネットに接続していない環境では、リンク先を開けないだけで、Lucivo の動作には影響しない（NFR-008）。

### FR-013: Markdown の保存

- ヘッダーの「保存」ボタンを押下すると、エディタの内容（YAML フロントマターを含む）を UTF-8 の Markdown ファイルとしてダウンロードする。
- ファイル名は、読み込んだファイルの名前を維持する（読み込んでいない場合は `untitled.md` とする）。
- ダウンロード完了後は、その保存時点の内容を「最後に読み込んだ内容」とみなし、別のファイルを読み込む際の破棄確認ダイアログ（FR-006）を表示しない。
- **背景・根拠**: 元ファイルへのローカル上書き API（File System Access API）は対応ブラウザが限定され、`file://` 環境での互換性に課題があるため、普遍的に動作するブラウザダウンロード方式を採用する。

### FR-014: 読み込み直後の読み取り専用

- ファイルを読み込んだ直後は、エディタを読み取り専用状態にする。エディタのヘッダーに「`閲覧` | `編集`」の 2 つ並びの切り替えを表示し、今の状態のほう（読み込み直後は `閲覧`）を選択中として示す（`DTP-006`）。
- `編集` を押すと編集可能状態に、`閲覧` を押すと再び読み取り専用状態に切り替わる。切り替えは、ファイルを読み込んだ後は表示したままにする。別のファイルを再度読み込んだ場合は、再び読み取り専用に戻る。
- 起動直後（ファイルを読み込んでいない状態）は、直ちに記述できるよう初期状態で編集可能とし、切り替えは表示しない。
- 読み取り専用の間も、保存（FR-013）、表示モード・スタイルの切替、図の操作・エクスポートは妨げない。
- **背景・根拠**: 本製品の位置づけは Markdown ビューアーであり、閲覧中のタイピングミスによる意図しない文書書き換えを防止するため。
- **背景・根拠（切り替えの形）**: 以前は「読み取り専用」のバッジとアクセント色の「編集」ボタンを並べていたが、ボタンの色が選択中の印に見え、読み取り専用なのに編集中に見えた。高速モード / Visualモードと同じ形の切り替えにして、今の状態を示す。読み取り専用に戻せないと、一度編集を始めた後の閲覧で誤入力を防げないため、`閲覧` で戻せるようにした。
