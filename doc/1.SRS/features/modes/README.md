# 発表モードの要求仕様 目次

発表モードは、ヘッダーの「発表」のドロップダウンから選ぶ見せ方である。Web 版で先に提供し、利用者の反応を見て、廃止するか、スタンドアロン版にも展開するかを決める（`doc/2.ARCHITECTURE.md` 4.16、`AGENTS.repo.md` 10 章）。モードの一覧は登録表（`src/ts/modes/modes.json`）で、本書の表は登録表と同じ行にする（`npm run lint` で確かめる）。

| モード                                   | 要求     | 要求仕様                   |
| :--------------------------------------- | :------- | :------------------------- |
| ズーミング・マップ（`zoom-map`）         | `FR-054` | [zoom-map.md](zoom-map.md) |
| プレイアブル・ダイアグラム（`playable`） | `FR-055` | [playable.md](playable.md) |

- 全体要求仕様書: [1.SRS.md](../../../1.SRS.md)
- 発表モードを追加・廃止するときに直す文書は、この `modes/` の中のファイルと、この目次の 1 行に閉じる（`ARC-MODE-010`）。
