# color-image（配色のイメージ）

「どんな気持ちを伝えたいか」から、色を選び、組み合わせるための考え方と道具をまとめる。

対象: $ARGUMENTS

## 0. 位置づけと進め方

| スキル       | 扱うこと                                                       |
| :----------- | :------------------------------------------------------------- |
| design-craft | デザイン全体の判断。11.2 で、配色を**どうまとめるか**の型（ドミナント・カラー、アクセントカラー、セパレーション、グラデーションなど）と、色の目的（機能の色か、印象の色か）を扱う |
| color-image  | 本スキル。印象の色を、**伝えたいイメージから選ぶ**方法を扱う   |
| dtp          | 工程と成果物。決めた配色は、デザイン仕様書の配色パレットに書く |

配色は、次の順で進める。

1. 伝えたいテーマを言葉にする（例: 「喜び」「おちつき」「知的な」）。design-craft 1 章の「誰に・何を・なぜ・いつどこで」を先に決める。
2. テーマがイメージスケール（3 章）のどこにあるかを決める。迷ったら、2 章の 3 つの属性で考える。
3. テーマのキーとなる色を 1 色決める。
4. 2 色めを、対比の強弱と、色相配色かトーン配色か（5 章）を意識して選ぶ。
5. 3 色めで、テーマのイメージを的確に仕上げる（4 章）。
6. 7 章の観点で点検する。

テーマごとの配色見本は [palettes.md](palettes.md) にある。配色を選ぶ場面で開く。

| 図                                               | 内容                                           | 参照する章 |
| :----------------------------------------------- | :--------------------------------------------- | :--------- |
| [assets/tone-chart.svg](assets/tone-chart.svg)   | トーン 12 区分を、明度と彩度の位置に並べた見本 | 1 章       |
| [assets/image-scale.svg](assets/image-scale.svg) | イメージスケールと、基本的な感情の配色の位置   | 3 章       |

## 1. 色の表し方（色相とトーン）

色は「色相/トーン」の記号で表す（例: `R/V` はさえた赤、`PB/Lgr` はあかるいはいみの青紫）。無彩色は `N` と明度の数字で表す（`N9.5` は白、`N1.5` は黒）。

**色相（10 区分）**

| 記号 | 色相 | 記号 | 色相 |
| :--- | :--- | :--- | :--- |
| R    | 赤   | BG   | 青緑 |
| YR   | 橙   | B    | 青   |
| Y    | 黄   | PB   | 青紫 |
| GY   | 黄緑 | P    | 紫   |
| G    | 緑   | RP   | 赤紫 |

**トーン（明度と彩度の組み合わせ、12 区分）**: 実際の色の見本は [assets/tone-chart.svg](assets/tone-chart.svg) を参照。

| 分類               | 記号 | 名前                              |
| :----------------- | :--- | :-------------------------------- |
| 純色               | V    | さえた（vivid）                   |
| 純色に近い         | S    | つよい（strong）                  |
| 明清色（純色＋白） | B    | あかるい（bright）                |
|                    | P    | うすい（pale）                    |
|                    | Vp   | ごくうすい（very pale）           |
| 暗清色（純色＋黒） | Dp   | こい（deep）                      |
|                    | Dk   | くらい（dark）                    |
| 濁色（純色＋灰色） | L    | あさい（light）                   |
|                    | Lgr  | あかるいはいみの（light grayish） |
|                    | Gr   | はいみの（grayish）               |
|                    | Dl   | にぶい（dull）                    |
|                    | Dgr  | くらいはいみの（dark grayish）    |

- design-craft 11.2 のトーン 12 区分と、ほぼ同じ分け方である。違いは、design-craft の「やわらかい（soft）」がなく、代わりに「ごくうすい（Vp）」があること。
- 色の印象は、色相よりもトーンで大きく変わる（design-craft 11.2）。同じ赤でも、`R/V` は興奮、`R/Vp` はやさしさ、`R/Dgr` は重さを感じさせる。

## 2. 色の 3 つの属性と、心への働き

色には、色相とトーンに代表される属性がある。属性をうまく活用すると、感情や気分などを表現しやすい。

### 2.1 暖色と寒色（WARM − COOL）

生理的な感覚に根ざすので、個人差が少ない属性である。

| 区分   | 色相      | 結びつく感覚                             | 連想         |
| :----- | :-------- | :--------------------------------------- | :----------- |
| 暖色系 | R、YR、Y  | 熱い・暑い、積極性、興奮・進出、発散     | 火、太陽、血 |
| 寒色系 | PB、B、BG | 冷たい・涼しい、消極性、沈静・後退、集中 | 海、空、朝   |

暖色と寒色の差は、派手なトーンほど表れやすい。地味なトーンや暗いトーンでは、派手なトーンよりも弱い。

### 2.2 明度（SOFT − HARD）

明度（明るさ）の違いは、心理的な重さや、硬軟の感覚と重なる。

- **明るい色**: 軽く、軟らかく感じられる。軽やかな気分やソフトなイメージに向く。
- **暗い色**: 重く、硬く感じられる。おちついた性格やハードなキャラクターの表現に向く。

### 2.3 清色と濁色（CLEAR − GRAYISH）

| 種類   | 作り方                       | 印象と向くイメージ                                         |
| :----- | :--------------------------- | :--------------------------------------------------------- |
| 明清色 | 純色に白を混ぜる             | 明るく澄んだ印象。さわやかなイメージ、かわいらしいイメージ |
| 暗清色 | 純色に黒を混ぜる             | 配色にメリハリをつけたいとき、ハードなイメージ             |
| 濁色   | 純色に灰色（白と黒）を混ぜる | 微妙なニュアンス。デリケートで複雑な気分や感情、悲しみや哀感を表すときに欠かせない |

### 2.4 属性を活かした配色の例

| 属性の活かし方       | 配色名と 3 色                                                                                                           |
| :------------------- | :---------------------------------------------------------------------------------------------------------------------- |
| 暖色の効果           | 喜び（YR/V、R/V、Y/V）、感謝（R/B、YR/P、YR/Vp）、盛り上がる（YR/S、RP/V、R/Dp）、パワフルな（P/Dgr、R/V、YR/S）        |
| 寒色の効果           | すがすがしい（PB/B、N9.5、B/P）、真新しい（BG/B、N9.5、PB/B）、冷静な（PB/Lgr、B/Vp、PB/L）、理数系（PB/Dgr、N8、PB/V） |
| 高明度のソフトな配色 | 癒やす（RP/P、G/Vp、P/P）、ロマンチックな（P/Vp、Y/Vp、B/Vp）、ふわふわ（R/Vp、N9.5、Y/Vp）、美少女（RP/B、Y/Vp、RP/P） |
| 低明度を中心としたハードな配色 | 悼む（PB/Dgr、PB/Dl、PB/L）、敬意（PB/Dk、P/Lgr、N1.5）、頼もしい（R/Dgr、YR/Dp、N1.5）、したたかな（N1.5、RP/S、RP/Dgr） |
| 清色的な配色         | さっぱりした（PB/Vp、N9.5、BG/Vp）、るんるん（RP/P、Y/P、R/B）、お調子者（R/V、Y/V、B/B）、几帳面な（PB/Dp、N9.5、B/V） |
| 濁色的な配色         | 感傷にひたる（P/Lgr、PB/Vp、PB/Lgr）、おだやかな（YR/Lgr、R/Gr、R/Lgr）、上品な（P/Gr、RP/Lgr、PB/Lgr）、すさんだ（B/Gr、N3、PB/Dgr） |

## 3. イメージスケール（テーマの位置を決める）

2 章の属性を軸にした地図に、言葉と配色を置いたものをイメージスケールという。テーマの言葉がどこにあるかを決めると、使う色の範囲が絞れる。図は [assets/image-scale.svg](assets/image-scale.svg) を参照。

### 3.1 WARM − COOL × SOFT − HARD（基本の 2 軸）

| 領域             | 集まる言葉 | 色の傾向           |
| :--------------- | :--------- | :----------------- |
| ウォーム・ソフト | 喜び、愛情など、ヒューマンな温かみと明るさを感じさせる言葉（うれしい、楽しい、好きな、やさしい、幸福な、かわいい、ほんわか系） | 淡いピンク・黄・橙 |
| クール・ソフト   | ここちよさのなかでも、さわやかな言葉（ここちよい、快適な、さっぱりした、爽快な、ピュアな、清楚な女性） | 白と、水色・青緑・淡い紫 |
| ウォーム・ハード | 激情、衝動など強い感情の動き、内面にくすぶるような気持ち（怒り、しつこい、暑苦しい、熱狂、タフな、悪役） | 赤・黒・茶・紫の、鮮やかか暗く強い色 |
| クール・ハード   | 悲しみ、恐怖、気持ち悪さなど、背筋が寒くなる感じの言葉（気持ち悪い、恐怖、憂鬱、真剣、知的な、紳士） | 紺・黒・灰色・暗い青 |

- 中央付近には、どちらにも寄らない言葉が集まる（おちつき、風情、淑女など）。
- 悲しみは、クールの側で、SOFT と HARD の境目にまたがる。

### 3.2 CLEAR − GRAYISH（第 3 軸）

横軸を CLEAR − GRAYISH に替えて見ると、別の分かれ方が見える。

| 領域                 | 集まる言葉                                                                                 |
| :------------------- | :----------------------------------------------------------------------------------------- |
| クリア・ソフト       | 喜び、ここちよさ、愛情など、「快」につながる言葉。プラスイメージの言葉が集まる、快のゾーン |
| グレイッシュ・ソフト | 言葉は少ない。悲しみの一部（悲しい、さびしさ、しょんぼり、もやもや）                       |
| クリア・ハード       | 怒る、ムカつくなど、怒りに関する言葉                                                       |
| グレイッシュ・ハード | 不快感を表す言葉と、悲しみを表す言葉                                                       |

- WARM と COOL の両端には、どちらも清色的な配色が位置する。そのため、2 軸では離れていた言葉（例: ウォーム・ソフトの「うきうき」と、クール・ソフトの「さっぱり」）が、CLEAR − GRAYISH の軸で見ると重なる。
- クリアの方向には、明快で動きのあるイメージが多い。グレイッシュの方向には、あいまいで動きの鈍いイメージが多い。

### 3.3 テーマの位置の例

気持ち・性格・キャラクター・擬態語を 2 軸に置いた一覧は、[palettes.md](palettes.md) の 2 章にある。テーマの言葉が一覧にないときは、近い意味の言葉の位置から推し量る。

## 4. 配色の組み立て

### 4.1 キー色から 3 色へ

配色するときは、まずテーマのキーとなる色を決める。2 色めは、色の対比の強弱や、色相配色かトーン配色かを意識しながら選ぶ。3 色全体でテーマのイメージを的確に表現することがポイントである。

単色に 2 色め、3 色めを加えていくと、イメージは多様な広がりを見せる。単色だけでは表しきれなかったイメージが表現できるようになる。

```text
PB/Lgr ─┬─ +PB/Gr「陰影感が生まれる」 ─┬─ +N6   → 不安
        │                               └─ +PB/L → 都会的な
        └─ +PB/Vp「繊細さが生まれる」 ─┬─ +N7   → 悲しい
                                        └─ +P/P  → 上品な

GY/V ───┬─ +Y/V「明るさが強調される」 ─┬─ +B/P  → 希望
        │                               └─ +YR/V → 陽気な
        └─ +PB/V「斬新さが生まれる」   ─┬─ +RP/V → 個性的な
                                        └─ +Y/V  → 奇想天外な
```

- 同じ単色から始めても、2 色めで方向が分かれる。同じ色相の濁色を足すと陰影、淡い色を足すと繊細さ、類似の色相の明るい色を足すと明るさ、離れた色相を足すと斬新さが出る。
- 3 色めで、具体的なイメージに決まる。

### 4.2 プラスとマイナスは見方で入れ替わる

色のイメージは、多面的、多義的、両義的である。同じような配色も、見方によってプラス面を強く感じたり、逆にマイナス面を感じたりする。

マイナスのイメージで使われやすい黒やグレー、P 系、RP 系の色も、視点を変えると、それらの色を使った配色でしか表現できない独特の気分や感情、性格がある。

| 共通の色              | プラスに見える配色              | マイナスに見える配色           |
| :-------------------- | :------------------------------ | :----------------------------- |
| グレー（N6）          | おごそかな（P/Dgr、N6、N3）     | 悲しむ（N6、P/Gr、N8）         |
| うす紫（P/P）         | エレガントな（P/P、R/Vp、RP/B） | はかない（B/Vp、P/P、N8）      |
| 赤紫と紫（RP/V、P/V） | 艶っぽい（RP/Dp、RP/V、P/V）    | 嫉妬深い（RP/V、N1.5、P/V）    |
| 柿色（YR/S）          | たくましい（Y/Dgr、YR/S、N1.5） | 暑苦しい（YR/Dp、R/Dgr、YR/S） |

- 色を「マイナスだから使わない」と決めつけない。組み合わせる色で、意味が変わる。
- 逆に、狙ったプラスのイメージが、組み合わせ次第でマイナスに読まれることもある。配色を決めたら、マイナスの読まれ方をしないかを確かめる。

### 4.3 多色の配色の作り方

4 色以上を使うときは、2 色の大きな面で印象を決め、残りの色を細い帯（アクセント）として挟む。帯の色で、華やかさやリズムを足す。

- 例（祝う）: 赤と白の大きな面に、黒・黄・赤の細い帯。
- 例（慟哭）: 濃紺の大きな面に、赤の細い帯。

## 5. 配色テクニックの 4 本の軸

テーマごとの配色の傾きは、次の 4 本の軸で説明できる。各テーマがどちら寄りかは、[palettes.md](palettes.md) の 1 章に示す。

| 軸                    | 一方の端                                                                     | もう一方の端 |
| :-------------------- | :--------------------------------------------------------------------------- | :----------- |
| 色相配色 − トーン配色 | 色相配色: 異なる色相を豊富に使う。動的ではなやか、豊かで味わいのあるイメージ | トーン配色: 色相を同一か類似に絞る。すっきりと簡潔 |
| まとまり − きわだち   | まとまり: 同一か類似の色相で、トーン差の近い色同士。おだやか、繊細           | きわだち: 反対の色相や明暗のコントラスト。力強く、ハッキリ |
| セパレーション − グラデーション | セパレーション: 明・暗・明、寒・暖・寒のように対比を強調。カジュアル、ダイナミック、モダン | グラデーション: 色を規則的に変化させる。リズミカル、デリケート |
| 清色的 − 濁色的       | 清色: ソフトで明るい、活動的、シャープ                                       | 濁色: おちつき、渋さ、深み、静的。シック、エレガント、ナチュラル |

セパレーションとグラデーションの作り方は、design-craft 11.2 の「目的別の配色」も参照する。

### 5.1 色相配色とトーン配色

- **色相配色**: 基調とするトーンの選び方に注意して配色することがポイント。
  - やさしい（RP/P、YR/Vp、P/P）: 暖色系を基調にした明るいトーンの色相配色で、やわらかな雰囲気。
  - わくわく（G/P、Y/V、R/B）: 期待に胸が高鳴る様子を、派手なトーンと明るいトーンの色相配色で。
  - リッチな（P/Dl、Y/S、RP/Dp）: ゴールドを中心に反対の色相を対比させ、味わいの豊かさを表す。
- **トーン配色**: テーマとして選ぶ色相のイメージ、次にトーンの差の強弱に配慮することがポイント。
  - 幸福な（R/B、R/P、R/Vp）: R 系の明るいトーンのグラデーションで、じわーっと感じる幸せな気持ち。
  - 自然体（YR/L、Y/Vp、YR/P）: YR 系と Y 系の類似の色相で、ゆったりとした雰囲気。
  - 都会的な（PB/Gr、PB/Dgr、PB/L）: クールで無機質な都会のイメージを、PB 系のトーン配色で。

### 5.2 まとまりときわだち

- **まとまり**: 対比を弱めると、配色がまとまりやすい。
  - はかない（B/Vp、P/P、N8）: P 系と B 系の明るいトーンと明灰色で、消え入りそうなはかなさ。
  - マイルドな（YR/Lgr、YR/L、YR/Gr）: マイルドな味わいのニュアンスを、YR 系の微妙なトーン差で。
  - 自信に満ちた（N1.5、R/Dk、P/Dk）: 自信に満ちた充実感を、黒と暗いトーンのまとまりで。
- **きわだち**: 色相、トーンともに対比感のある色同士を組み合わせる。
  - 期待（BG/B、Y/B、PB/V）: Y 系の明るいトーンを中心に反対の色相を対比させ、明るい未来への期待感を。
  - アヴァンギャルド（P/Dp、GY/V、RP/V）: GY のビビッド・トーンを中心に、反対の色相を対比させて過激さを。
  - 名声（R/V、Y/S、P/Dk）: P/Dk とゴールドの対比で名声を示し、アクセントの赤で強さを。

### 5.3 セパレーションとグラデーション

- **セパレーション**: 色と色の間に、対比する色を挟む。
  - カラッとした（YR/B、Y/Vp、B/P）: 明るいトーンの色相配色を Y 系でセパレーションし、カラッとした雰囲気。
  - きちんとした（PB/Dk、N9.5、PB/S）: PB 系の間を白でコントラストをつけ、きちんとした印象。
  - エネルギッシュな（R/V、YR/Dgr、YR/S）: R/V と YR/S の間を暗い YR/Dgr で引き締め、力強さを強調。
- **グラデーション**: 色相のグラデーション、トーンのグラデーション、それらのミックスがある。
  - 希望（BG/B、GY/P、Y/B）: 明るい未来への希望を、BG 系・GY 系・Y 系の色相のグラデーションで。
  - ゆったりした（Y/Vp、YR/P、R/P）: 3 色とも色相を変え、明暗の変化も意識して、ゆったりとした雰囲気。
  - 盛り上がる（R/B、R/V、R/Dp）: 徐々に熱を帯びていく様子を、R 系のトーンのグラデーションで。

### 5.4 清色と濁色

- **清色**: 「パステルトーン」と呼ばれる配色は、明るい清色トーンの色相配色で構成されている。
  - メルヘン（P/Vp、Y/Vp、BG/Vp）: 童話のようなかわいらしい世界を、明るい清色トーンの色相配色で。
  - キラキラ（GY/B、Y/B、B/P）: キラキラした輝きを、Y/B を中心に清色的な明るさで。
  - 自由な（PB/V、N9.5、YR/V）: PB と YR の反対の色相の間を白でセパレートし、開放的な感覚を清色トーンで。
- **濁色**: グレー系や、Lgr、Gr、L、Dl の濁色トーンを使う。
  - 切ない（P/Gr、RP/Lgr、PB/Lgr）: しんみりと感傷にひたる様子を、PB 系と P 系の濁色トーンで。
  - おだやかな（YR/Lgr、R/Gr、R/Lgr）: YR 系と R 系の濁色トーンで、平穏でおだやかな様子。
  - なつかしむ（N3、YR/Gr、YR/Lgr）: 暗灰色と YR 系のグラデーションで、しみじみと追想する気分。

## 6. 画面デザインへの応用（推論）

1〜5 章の考え方を、Lucivo などの画面デザインに当てはめたもの。

| 考え方               | 画面デザインでの当てはめ方                                                              |
| :------------------- | :-------------------------------------------------------------------------------------- |
| テーマの位置を決める | Visualモードのスタイルや発表モードを作るときは、狙う印象を言葉にし、イメージスケールの領域を先に決める。design-craft の擬人化力（どんな人か）と、領域（例: クール・ハードの「知的な」）を揃える |
| 3 つの属性           | 講演や展示で熱量を出したいときは暖色・高彩度、集中して読ませたいときは寒色・低彩度に寄せる。明るい背景（Light）は SOFT 側、暗い背景（Dark）は HARD 側に寄りやすいので、Dark で SOFT のイメージを出すときは、図形や文字の色を淡い清色にする |
| キー色から 3 色へ    | スタイルの配色は、キー色 1 色（見出しや主役の図形）、2 色め（面や区切り）、3 色め（アクセント）の順に決める。全部の色を同時に決めない |
| 多色の配色           | 4 色以上を使うときは、背景と主役の面の 2 色で印象を決め、残りは細い線やバッジにとどめる |
| プラスとマイナス     | 黒や紫を使うスタイルは、高級感や重厚感のつもりが、不安や不快に読まれないかを確かめる。キー色だけでなく、組み合わせで判断する |
| 色相とトーンの記号   | 配色の指定や検討の記録では、色を HEX 値だけでなく、色相とトーンの言葉（例: 「さえた赤」「あかるいはいみの青紫」）でも書く。意図が伝わり、別の色に差し替えるときも、トーンを揃えられる |

## 7. 点検の観点

- [ ] 伝えたいテーマを言葉にし、イメージスケールの領域を決めてから色を選んだか
- [ ] 暖色と寒色、明度、清色と濁色の 3 つの属性が、テーマの方向とそろっているか（例: 「おだやか」なのに、さえた高彩度の色ばかりになっていないか）
- [ ] キー色を決め、2 色めで対比の強弱と、色相配色かトーン配色かを意識したか
- [ ] 3 色全体で、テーマのイメージを表現できているか。2 色だけで止まって、イメージがぼやけていないか
- [ ] 配色テクニックの 4 本の軸のどちら寄りかを、テーマに合わせて選んだか
- [ ] 狙ったプラスのイメージが、組み合わせ次第でマイナスに読まれないか
- [ ] 濁色や暗いトーンを並べたとき、隣り合う色の明度が近すぎて、境目がつぶれて見えないか
